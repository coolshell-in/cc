内部资料，仅供相应学员复习

本讲义来自扬州菩提寺广厚法师，我们通过AI提取长篇讲义的摘要。

> 适用范围：本系列其余各章节的讲经口语稿（逐字稿、录音整理稿）。
> 目标：将"听"的讲稿，改编为"精读"的书稿。

---

## AI摘要提示词

**关键要素（必须包含）：**
1.  **核心结论**：文章主要观点或发现。
2.  **主要论据**：支撑结论的基本道理或逻辑。
3. **行动建议**：基于文章，提出数条具体、可操作步骤。
4. **关键词**：请列出与佛法/佛教/佛学相关的专业术语/关键词及其简单解释或资源链接。

**格式与风格要求：**
- **结构**：使用要点清晰的小标题。
- **语言**：精炼、客观、专业。
- **篇幅**：每篇控制在1500字以内。


**请避免：**
- 复制长段原文。
- 包含次要细节。
- 添加个人评价。
- 给每个关键词都使用加粗字体。
- 类似1，2，3这样的序号。

请基于以上要求，将长文提炼成一份快速阅读的摘要。

## 一、改编总原则

1. **客观陈述**——去掉第一人称（学人、我）与第二人称（你、大家、我们），全文改为对佛法义理的客观讲述。
2. **书面语体**——采用文言与白话相间的佛教论疏式文风，庄重而不失晓畅。
3. **逻辑收束**——按论证单元分段，合并重复申说的内容，一段一意。
4. **精简优先**——删净口语赘词，压缩文字量，一般较原文减少三至四成，核心信息不得丢失。

---

## 二、改编七步流程

### 第一步：通读原文，理清论证逻辑

先不急着动笔，通读全篇，画出原文的逻辑链。口语稿常把同一层意思反复说几遍，要先识别出"哪几句是同一个论点"，为合并做准备。

### 第二步：按论证单元分段

口语稿往往是一大段连绵语流。按"一个段落只讲一个意思"来切分：

- 段首放主题句，全段围绕它展开；
- 整体结构遵循传统讲记的"**总说—分述—结劝**"：开头释题，中间分层论述，结尾收束归劝；
- 常见分段依据：释题 / 知见 / 现状分类 / 举例设问 / 方法劝修。

### 第三步：去除人称

| 原文人称 | 处理方法 | 示例 |
|---|---|---|
| 学人、我 | 删除，或转为"此经""今""本文"等 | "学人已经讲过两次" → 删去 |
| 你、大家、我们 | 删除，或转为客观陈述 | "你就问他一个基本的概念" → "试问" |
| 口语设问 | 保留设问形式，但书面化 | "你问他：什么是「无我」？" → "试问：何谓「无我」？" |

人称删净后，文本从"某位法师的个人分享"变为"佛法义理的客观陈述"，才具备著作的体例感。

### 第四步：去除口水话

以下口语赘词与表达，见到即删（或改写），不必犹豫：

- **语气词、口头禅**：那、所以说、其实、比方说、就是说、当然、就是、的话、等等、那么
- **口头强调式重复**：很多很多、很少很少、讲不出来、说不清楚（在句中重复出现的部分）
- **口语过渡句**："讲这么多就是希望大家……"这类口头收束语，改写为书面总结
- **冗余问答**：口语中自问自答的铺垫句，保留问题、删去铺垫

### 第五步：书面化改写

- 适当使用文言虚词点缀：**者、然、盖、即如、是故、鲜矣、其故在于**
- 保留并规范佛教术语：道次第、菩提心、缘起、空相、无我、熏修、觉慧、自利利他
- 短句为主，四字句与文言句式穿插，形成节奏；
- 删除现代口语感叹与口头禅，不夹带"真的""特别""非常"这类口语修饰。

### 第六步：拟定段落标题

- 每段标题四至八字，取自该段核心立意；
- 用名词短语，如"释题：三经总说""首重知见，次第入手"；
- 全篇统一编号：一、二、三……，标题风格保持一致；
- 标题须与段意严格对应，避免大而空。

### 第七步：复核

对照原文逐项检查（见第六节质检清单），确认信息无遗漏、风格统一后再定稿。

## 三、正反例对照

| 原文（口语） | 改编后（书稿） |
|---|---|
| 那《八大人觉经》这部经很短，学人已经讲过两次 | 《八大人觉经》篇幅虽短 |
| 因为这部经它道出了我们修学佛法的一个次第 | 此经揭示修学佛法之次第 |
| 所以说我们看佛教徒现在的一个基本的状况分两种 | 今观佛教徒之修学状况，大抵可分两类 |
| 你问他：什么是「诸法空相」？ | 试问：何谓「诸法空相」？ |
| 所以他就不能说个所以然 | 语焉不详 |
| 讲这么多就是希望大家经过这八条觉悟的学习 | 望依此八条觉悟之修学 |

## 四、段落标题示例

以《八大人觉经》篇改编成品为例：

1. 释题：三经总说
2. 首重知见，次第入手
3. 当今佛教徒之两类修学
4. 试问空相与无我
5. 下手处与日常熏修

---

## 五、改编成果的验收标准

一篇改编合格的文章应当：

- 通篇无第一、第二人称；
- 无口语赘词与口头禅；
- 段落边界清晰，一段一意，各有标题；
- 重复论证已合并，文字量较原文明显减少；
- 佛教术语保留且用法规范；
- 论证层次完整：总说—分述—结劝不缺环；
- 读起来像一部书的一节，而不是一份讲稿。

---

## 六、逐篇质检清单

改编每一章时，按下表逐项勾核，全部通过方可定稿：

- [ ] 全文无"学人、我、你、大家、我们"等第一、第二人称
- [ ] 无"那、所以说、其实、比方说"等口语赘词
- [ ] 段落按论证单元划分，每段有主题句
- [ ] 重复申说已合并，未出现同一论点前后三遍
- [ ] 佛教术语保留且书写规范
- [ ] 对照原文要点，核心信息零遗漏
- [ ] 文字量较原文减少约三至四成
- [ ] 段落标题与段意一致，编号与风格全篇统一
- [ ] 起承转合完整：释题开头，收束归劝结尾
