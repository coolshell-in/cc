    八热八寒·地狱众苦

    一、承前：以境界验心 #

    上堂论「多欲为苦」之粗细，理虽浅白，真要跨过却极难。累劫生死习气，已令人对「欲」养成坚固依靠，男女之欲染着缠绵，最难止息。学佛多年、听经闻法十数年，若细察自心，日夜所为与未学佛者未必相去几何。学佛可以境界炼心：遇所爱之境仍贪着，六根对六尘常是颠倒迷痴；大经大论听得多，境界现前用得上的却少。与人相处，凡夫仍是一颗爱憎取舍之心；不遑论发菩提心度化对方，能不起嗔恼已属不易。

    故须静心自问：修学多年，究竟为脱生死，抑或真为菩提？若真为生死、为成佛，何故仍与世间人、同参道友斤斤计较？顺逆境界皆是考题，当常观自己起心动念：今日遇此境界，考得几分？可仿了凡每日记功过，每日起烦恼亦自打分。此即修学之验证、感应道交之所在——感应道交，不过是拿现实给自己答题。

    二、六道别苦与地狱总说 #

    生死疲劳之别苦，随六道各有其苦境。其中地狱道之苦最为严重。地狱分为大有情地狱与孤独地狱：大有情地狱即根本地狱，谓八热地狱、八寒地狱；每一八热、八寒地狱周边各有近边地狱（十六小地狱）。

    地狱之所在，《长阿含经》云：四天下外有八千天下围绕。四天下即四大部洲——东胜身洲、南赡部洲、西牛货洲、北俱卢洲——位于须弥山四方，山上有日宫月宫。四大部洲之外有八万天下围绕，其外大海水环绕，海水外有大金刚山，山外复有第二金刚山；地狱即处两金刚山中间之大铁围山内。日月有大威神力普照世间，独不能照入两山之间，故八热地狱与其十六小地狱永处黑暗。

    自本性言，何期自性，本自清净；自缘起言，何期自性，本自具足。具足人法界，亦具足地狱法界，各有其缘起。地狱非虚无抽象之境，实有地点、名称与缘起；诸法因缘生，地狱与人间法界无异。具神通力可往观之，具重大罪业亦受牵引而往。

    三、八热地狱总名 #

    八热地狱八种：等活地狱、黑绳地狱、众合地狱、号叫地狱、大号叫地狱、烧热地狱、极烧热地狱、无间地狱。一一详述。

    四、等活地狱：铁爪互斫，冷风复活 #

    等活地狱众生，以业力故，手生铁爪，相见即起极强嗔恨，以爪互抓其身肉，亦抓自身，抓至血肉竭尽。地狱中复由业力化现刀剑凶器，罪人执之互相砍杀，砍死之后，一阵冷风吹来，众生复平等活转，再执刀爪相斫，如是循环。

    业力有上中下三品，若无忏悔，罪报未尽，不得径入次狱，先转入等活地狱周边之十六小地狱。

    五、十六小地狱（上） #

    十六小地狱，从黑沙至寒冰，一一道来。

    黑沙地狱：热风暴起，黑沙吹附罪身，自皮烧至骨，火焰绕身回旋，因业坚固烧而不死。

    沸屎地狱：狱卒逼罪人抱通红铁丸，复令置入口中，自喉烧至腹，无不焦烂；沸腾屎尿中有铁嘴虫啃食其身，乃至见骨，业报未尽，求死不得。

    铁钉地狱：罪人被缚热铁板上，四肢展开，五百铁钉钉身，经无量劫方业尽转出。

    饥饿地狱：罪人饥渴，见热铁丸、热铜汤即扑而饮之，自喉烧穿至腹；业尽方出。

    铜镬地狱：狱卒执罪人倒提，投入沸铜汤中，随汤涌沸上下回旋，身坏烂熟，万毒并至，死而不死。

    多铜镬地狱：狱卒以铁钩自镬中钩出罪人，复投他镬，辗转不已，悲叫苦毒。

    石磨地狱：罪人被置于火热石上，展舒手足，大热石碾身来回搓磨，骨肉糜碎，业尽方出。

    六、十六小地狱（下） #

    脓血地狱：沸脓血温度不可计量，罪人东西驰走，遍身烧烂，复因饥饿不得不食沸脓血，自喉入而直泄于下，肠腹早已烧穿。

    量火地狱：有大猛火聚，狱卒逼罪人持铁升撞火，烧红铁棍在后驱赶；遍身烧燃，吟呻号哭，死而不死。

    灰河地狱：灰汤涌沸，纵广五百由旬，中有铁刺纵横，岸上剑树林立。罪人随波上下，铁刺刺身，内外贯穿；勉强上岸，又为刀树伤破，豺狼追逐啃食，攀剑树则手绝足断，皮肉堕尽唯余白骨，铁嘴乌鸦复啄其头；不得已跳回灰河，冷风一吹皮肉复生，循环受苦。

    铁丸地狱：狱鬼以通红铁丸掷罪人，业力故躲不可避，身被投烂着火，万毒并至。

    釿斧地狱：狱卒以利斧斫罪人手足耳鼻，不遽断之，如雕刻般徐徐斫削骨肉，苦毒号叫。

    豺狼地狱：群狼䶩龊罪人，肉堕骨伤，脓血流出，死而不死。

    剑树地狱：暴风吹剑叶，割伤头面身体，血肉淋漓；铁嘴乌鸦啄其眼珠，锥痛万端。

    寒冰地狱：大寒风吹身，遍体冻伤，皮肉坠落，苦毒叫唤，历无量劫方得业尽。

    七、等活之因与寿：一失人身万劫不复 #

    罪人入地狱而难出，在于生前造罪时心念坚固，无惭愧忏悔。日课拜八十八佛，即长养惭愧忏悔之心，折伏罪业；临命终一刹那失足堕狱，有惭愧心者亦易出。不拜佛、无惭愧，起烦恼又坚固，则难出；邪见之人不自认有罪，须将一切地狱历遍。故曰不怕念起，只怕觉迟。

    等活地狱之业因：杀业重，及毁正见、诽谤正法。其寿量：人间五十年为四天王天一昼夜，四天王天五百岁为等活地狱一昼夜，等活有情寿命五百岁，尚有十六小地狱在后。一失人身，万劫不复，三恶道之苦痛漫长如是。当知讲经当下，无量众生正在地狱受铁丸铜汤之苦，业感如是，非虚言也。

    八、黑绳地狱 #

    狱卒以炽热黑绳缠缚罪身，烙出黑线，复执斧锯沿线锯割；锯至下方，业力故上身复合，再锯再合，周而复始。又有通红铁绳交横悬挂，狂风骤起，铁绳落身，皮焦肉开，骨髓沸腾，而罪人死而不死。

    其苦十倍于等活地狱。业因：杀生、偷盗、不孝父母、诽谤三宝。寿量：人间百岁为三十三天一昼夜，三十三天千岁为黑绳地狱一昼夜，寿命千岁。地狱极苦，念念逼迫，无从思惟人身难得、佛法难闻；故佛以光壁撒豆、乌龟穿孔喻人身之难得。

    九、众合地狱 #

    众合地狱又名推硖地狱。罪人见广大平原，前有二山，形如牛、羊、猪等；狱卒驱赶，罪人奔入山谷欲避，二山即由业力合拢挤压，肉骨碎裂；脚下铁板通红，脓血被蒸腾上涌，倍加其苦。山现畜生形，因其平生好杀此类众生。复有大铁象哮呼蹴踏，身碎脓流；或卧热石上以大石碾压，铁杵从头捣至足，血肉糜烂，死而不死。

    业因：杀生、偷盗、邪淫。寿量：人间二百年为夜摩天一昼夜，夜摩天两千岁为众合地狱一昼夜，寿命两千岁。

    学法调心，大乘般若与藏教法皆须修学：但学《法华》《楞严》义理，久则麻木；须以地狱苦之藏教观刺激厌离心，建立基础，再学大乘方易入心。

    十、号叫与大号叫地狱 #

    号叫地狱：狱卒以镬汤煮罪人，或置于鏊上（如铁板烧然），以铁叉自下贯顶，翻覆空中，复以热铁棒从头打至足，足处头复，循环不息。业因：杀盗淫酒，及嗔心极重者。寿量：人间四百年为兜率天一昼夜，兜率天四千岁为号叫地狱一昼夜。其苦十倍于众合地狱。

    大号叫地狱：苦相如前而倍加剧烈。业因：犯五戒。寿量：人间八百年为化乐天一昼夜，化乐天八千岁为大号叫地狱一昼夜，寿命八千岁。

    十一、烧热与极烧热地狱 #

    烧热地狱（烧炙）：狱卒驱罪人入猛火城，城门即闭，东西南北四面铜墙皆被猛火烧红，上下左右猛火灌烧。劫坏火灾之热，不足与地狱火相比；人间之火较之地狱火，清凉如水。罪人见东门开，奔之将及，门忽复闭；西门又开，复奔西门，东西南北驰走不已。又有红铁楼，上楼下楼皆炽火，无处可避。最可怖者，死而不死——以众生造罪时，造前、造时、造后三心坚固决定，业种坚固，故受报时死不掉。

    业因：犯五戒、生邪见。寿量：人间一千六百万岁为他化天一昼夜，他化天一万六千岁为炙热地狱一昼夜，寿命一万六千岁。忏悔之法：可将所造罪业书于小纸，置佛前日日礼拜忏悔，经年烧毁；业性本空，业者乃心感果报之功能，藉惭愧忏悔之力，可使此功能转向，然仍须依缘起对治，非徒知空理可灭。

    极烧热地狱：苦相与烧热相似，而苦更剧、寿更长。业因：犯五戒、邪见，及污净戒僧尼。寿量：半个中劫。一小劫者，人寿十岁，百年增一岁至八万四千岁，复百年减一岁至十岁，一增一减为一小劫；半个中劫，已不可计量。

    十二、无间地狱 #

    无间地狱即阿鼻地狱，《地藏经》谓有五无间：时无间、趣果无间、苦无间等。狱卒扒尽罪人之皮，以皮缠身，平卧红铁板，火车轮碾身，皮肉碎落；或固定铁板，数百由旬猛火齐集一身，一人遍满地狱，多人亦遍满，相不妨碍，处处皆见自身受刑。狱卒复以铁畚箕盛通红铁砂撒身，自外烧内；或逼罪人爬大火铁山，或压其舌于铁板以牛耕之，耕而复生，往复不已。

    业因：五逆重罪。寿量：一个中劫。八热地狱及其十六小地狱之苦，至此为极。

    十三、近边地狱 #

    每一大地狱周边之十六小地狱，即其近边眷属地狱，从黑沙至寒冰。其苦较大地狱稍轻，以众生造罪所缘境、心态不同，罪品分上中下，实则无量品；众生烦恼力度无量，故地狱刑罚器具亦无量。

    十四、八寒地狱 #

    八寒地狱处于雪山冰川环抱之中，众生裸身受冻。依冻伤相状与所发声音立名：具疱地狱（身冻起疱）、疱裂地狱（疱裂成创）、额哳咤（紧牙地狱，寒苦倍增、咬紧牙关）、郝郝（阿啾啾，舌不能动，唇间出声）、虎虎婆（齿唇皆不能动，唯咽喉振气出声）——此三以声立名；青莲花地狱、红莲花地狱、大红莲花地狱，皮肉层层拆裂，如莲花绽开，至大红莲则爆裂数百片，一层苦甚一层。

    临命终时之寒热相：觉寒而屡索被盖者，一念求暖，即入八热地狱；觉热而蹬被者，一念求凉，即入八寒地狱。八寒地狱复有铁嘴虫钻入冻裂创口，咬啮不止。其寿量：最短之具疱地狱，以二百丈深盆盛满芝麻，每百年取一粒，取尽方尽；其后七狱，苦与寿俱增二十倍。

    十五、孤独地狱 #

    孤独地狱为地狱中最轻者，处所无定：临终心识随执取而投，或藏山谷、水中、树干、茶杯，乃至绳帚、瓦罐、门柱。投柱则撑屋受苦，投树则随伐木而感肢解之痛。诸法唯心所现，心识能变现无量果报体。此狱以别业为主，然亦有共业——无垢光尊者曾见五百比丘同受孤独地狱之苦；《僧护传》载僧护比丘至孤独地狱，见诸出家人脚被烧焦，以石器互击，饭时暂止，食已复击。

    十六、地狱苦之修观 #

    地狱相状无量：众生烦恼无量，地狱即无量，经中不过粗分大地狱、十六小地狱而已。闻地狱苦而不修观，则不能入心。修观之法：静坐中观想自身真切转生于八热地狱，令怖畏心生起；复转念：今未实堕地狱，仅一念之想已恐怖如此，况真实受报？再观真实堕落之众生不可胜数，三恶道充盈，而彼等皆是历劫轮回中之父母。

    转想今生父母儿女：若不学佛，命终多堕恶道；而自身得暇满人身、遇佛法与净土，实为万幸，当趁此身决志成就解脱，方能度脱父母眷属。又念过去生必造过杀盗淫妄重罪，若不忏悔，即是肯定此业，临终现行之机率极大；故须诚心忏悔，誓不复造，纵遇命难亦不造地狱之业，并发悲心度化亲眷。

    十七、总结劝修：常思地狱苦 #

    教理之学，多则易生麻木：听《法华》《楞严》，仿佛自在幸福、大事已办；般若一空，佛性宛然。然未开悟、未见性、未大开圆解，无证量则有无量可能。六根对六尘，几时保持觉照正念？该贪仍贪，被说仍嗔，觉照未起作用，多分仍是颠倒愚痴——临终堕三恶道之机率极大。昔泰国南传有禅定僧人，以神通观察，谓现今众生百分之九十五以上堕三恶道，得人身者不及百分之五。

    故须每日拜佛忏悔。罪业由身口意三业而造，忏悔亦须三业齐修：非徒好乐教理听经闻法可灭罪，身须拜下，口须发露。自觉良好时，当思地狱之苦。印光大师特重「常思地狱苦」，以生厌离、发菩提心。《八大人觉经》所以讲得细，正在予人以具体思惟过程；知得越具体，心越有力量。

    六道别苦，地狱已竟；下堂当述余道之苦。

    结语：合掌回向，愿共成道业。
