    一、深入无常：世间国土之根源 #

    前两讲观察「世间无常、国土危脆」，多从有形有相之因缘变化入手，此属粗分初步之观察。进一步当问：世间国土如何形成？知其形成之根源，方知其何以无常。此根源不在外境，无非八识所现、阿赖耶识所现。由粗分而细分，观察至于根源，则不再一味肯定或否定外在世界。

    就大分而言，山河大地为人道众生共业所感；就别业而言，各人认知之世间各有不同。同处一地，所见各异。在大分共业之世间中，众生各依别业而有不同认知；究极而言，各走各路。外在一切随各人业力展现，即唯心所现。故解决问题之根源在自心，不在外界。

    业力为因，无常本然 #

    「世间无常，国土危脆」，何以无常？业力不稳固。众生以为世间稳定，实为错觉。稳定之当下，刹那生灭，成住坏空，无一刻不然；阿赖耶识不断释放宿世业力，业力刹那因缘和合、因缘别离。共业所感之世间，共业将尽时，该坏者自坏。如汶川地震、海啸等天灾，转瞬之间十数万人殁；战乱纷起，亦是共业成熟。世间种种不稳定即在眼前，众生仍以为稳定，因宿世颠倒习气已成习惯。

    外在国土稳不稳定，根源不在外在，而在内在之国土——阿赖耶识中之业力。此业力如定时炸弹，不知何时成熟，无法掌控。世间人谓之偶然，其实因缘成熟而已。今日此人不在，明日彼人不在；旧时眷属、同学，存者几人？国土非此灾难即彼战乱，从来未稳定过。所谓外在，皆心业力所变现，本无单纯之外在，言外在不过方便。一切因缘非所能掌控；世间人所谓掌控，只是福报善业力支撑。业力不多给一分、不少给一分，如实展现。如父母欲子女依己意发展，往往相违：自尚不能主宰，何况主宰他人。轮回路险，一息不来，即入三途，因内在国土将熟。

    执常造业，轮回相续 #

    观「世间无常、国土危脆」，当知世间自始即由心业力形成。面对世间，莫执为常，亦莫以为有独立外在之器世间——外在世间与身心世界不相离。《大智度论》云：「一切有为法，因缘生，故无常。」缘起之心业力本身无常生灭，因缘亦不离心业力。故说无常，不必处处外求条件；条件本身即是无常，本质根源即是生灭变化。无常者，其本质从来非是常；众生之所以苦，正在于此。

    若不达根源而执无常为常，攀缘造业，又成新业力，再成新根身器界，复执为常，再造新业——生死轮回、痛苦相续，由此而来。心创造器世间，有情众生执以为常，依止器世间生起六根，六根缘六尘，相互肯定；众生自造此世间，复受用此世间，受其影响，继续颠倒，赋其意义，肯定造业，又成新世间。众生在自己创造之世间中争斗嗔骂，轮回如此而来。抓不到根源，修行似修解脱而实未修，即使不造杀盗淫，一分执取仍令轮回。修行不得要领，即在顺生死流。故第一觉须以大篇幅深入，因它建立最初之根本认知；此一条件不立，后之断恶修善、发菩提心相应功德皆不能成就。

    二、别离行 #

    经云：「别离行：依内外二种别离，应知诸行是无常性。」

    此前已观变异行（内事、外事）与灭坏行（刹那生灭、自然坏灭）。变异行中，内事就有情正报身心观察，外事就依报环境观察；灭坏行则进一步说明，表面粗分之变化实为刹那微细生灭，其根本推动力是业力——因缘只是增上缘。本讲继观别离行。

    内在别离 #

    内在别离，指正报身心失去自主性。如因破产、犯罪等因缘，人身失去自主；或误学邪教，思想失其自主，听人操控。身心世界无自主性，即内在别离相。

    外在别离：钱财五家共有 #

    外在别离，指依报资具之丧失。佛陀言钱财五家共有：水、火、盗贼、国王与不肖子。水灾火灾破坏，恶王没收，盗贼偷窃（过去相欠，今生来偷），不肖子挥霍败家（或生而患病，人财两空）。此皆依物质粗分观察，借空间描述无常境界。

    三、法性行与合会行 #

    以上诸行借空间描述无常，法性行、合会行则就时间立说。

    法性行：未来必坏 #

    经云：「谓即所有变异无常、灭坏无常、别离无常。于现在世犹未合会，于未来世当有法性。」

    变异、灭坏、别离诸无常，其事虽未发生，未来必当如是：财产必散，眷属必离，所拥一切必失，此是决定性之理。现在贪爱之境界、执取之眷属、贪恋之色身、所有之财富，皆不可保任，未来必当败坏消失；纵然难以割舍，业力令其别离，非己可主。心之感受亦然：乐受必失，勿贪着；烦恼痛苦必过，勿执取——其法性即无常。苦受、乐受乃至舍受，皆是无常法。想不开时当思：烦恼痛苦一时而已，时间会带走一切，因其本是无常。

    合会行：当下即无常 #

    经云：「谓即如是变异无常、灭坏无常、别离无常。于现在世合会现前。」

    此三种无常相，当下即合会现前：此时此刻，正处其中。静心观察，眼前一切境界（依报、正报）皆是阿赖耶识之相分，如电影一刹那一刹那生灭，因生灭太快，观之似相续；如电灯一秒钟生灭百余次，见之似常。故当下已具足一切无常相，当下即在生灭生死之中。法性行等是就心粗者之方便说；诸法真实相，即合会行——当下无常生灭。故观无常，不只观已发生或必发生之事，时刻当下即是无常，只是心粗难察，未闻法者难以了知。

    四、无常观之重要 #

    以上详释无常形相，了解无常即苦谛。初学者宜于粗分无常多花时间思惟。经中所述看似简单，然时时刻刻能有几人体会？东西坏了就扔，体会不到无常相，生死心便提不出来。生死心多在微细观照中生起。众生心常安住"不死"之状态，知死而不觉死之将至，因只听闻无常道理，未能体会。粗分无常之观察建立不起来，即不能对世间生厌离心——此是厌离之基础。

    福报大者尤须观察 #

    福报大者乐受多、心粗，沉于欲望，难体会无常。贫乏之人临终易跨出，因放一分即可；福报大者须放十分。若无无常观念，又无布施习惯，一味受用福报，临终一念必与悭贪相应；一生追求之资具眷属，看似福报，反成障碍。福报不会用，即生死最大之障碍。临终业力令其别离，而习惯执取、拼命掌控，如生龟脱壳。

    平常受用念念执取 #

    求往生者，粗分无常观念必先建立；对现有资具、恩爱眷属，提前做好心理准备，建立"万般带不去，唯有业随身"之观念。最好将资具化作助道资粮；否则临终即为障道、障往生之因缘。平常受用资具，念念皆夹执取心而不自觉；无觉照智慧，念念皆与执取相应。如购新车，欢喜之当下，念念皆加强对车之执取。执取成习、养成等流，临终无常到来，无能为力感与内心痛苦挂碍，将大于色身之苦。不可小看平常受用，须念念观照；用功持戒严谨之人，往往为平常生活习惯所障，若不能提起觉照，即因习惯性念念执取。

    生死心之建立，谛闲大师云：「道心之发，实由欣厌；然众生久在迷途，若无佛法常时熏习，欣厌即无从生起。」须长时听经闻法，产生观照力，念念觉起，方能体会生命真相本是无常。欲求往生、欲解脱生死者，不宜于眼前受用资具多花时间，当将生灭因缘之资具转为助道资粮，莫待病床加护方恍然大悟。渐渐观照，念念觉照身心世界，方能渐渐松脱执取。

    生死心非口头之念 #

    生死心之生起，不是面对佛菩萨时"世界很苦、想早点走"之口头一念，而是在现实因缘中，遇大风大浪，已无昔日强烈之执取心——此即通过无常体会、观照，知其虚妄。从现实因缘观照执取心，心渐松脱娑婆；此时念佛，求生心自然而出，心有所住，住于极乐，因娑婆已无诱惑执取之力。若完全感不到无常，则生死心未生起，念佛无异于乡谚"上坟烧报纸"——自欺欺人。

    五、四大苦空 #

    「世间无常、国土危脆」偏重依报世间，以下「四大苦空」观正报世间。四大有二：实四大与假四大。

    实四大与假四大 #

    「实四大：地大性坚，能支持万物；水大性湿，能收摄万物；火大性暖，能调熟万物；风大性动，能生长万物。」从性上讲，四大为坚、湿、暖、动四性（生长、收摄、调熟），其性不相和合。色身亦具四大，一大出问题，其余皆出问题：骨属坚性，骨折则诸性俱受影响。故四大本身即苦。假四大，即世间立名之地、水、火、风，属共同认知之名言。内四大即正报人身，外四大即山河大地。

    三苦 #

    「苦空」先释苦。四大色身果报中有苦受，亦有乐受、不苦不乐受；从第一义谛而言，三种感受本质皆是苦。

    • 苦苦：「一切有为法，性自逼迫，更加逼迫。」四大果报体本有逼迫性（性苦），复加逼迫，即苦苦。如人身上长褥疮，已极痛苦，复以热汤浇之。以病言之：四大平衡失调，地大失调生一百一十种病，四大失调合共四百四十种病。地大偏多则身僵，水大偏多则浮肿，火大偏多则燥热发烧，风大失调则行动不自在。
    • 坏苦：乐受所生之苦。如身体健康时觉乐，忽而生病，乐受消失变为苦受，即坏苦。
    • 行苦：不苦不乐之受，有二义：一不安稳——不能保存、不能恒常相续，因缘触动即转苦乐；二粗重——心粗故不觉，龙树菩萨喻：毫毛置手掌无觉，置于眼中即觉；打坐时生轻安乐受、身若不存在，出定即觉身粗重。

    无常故苦 #

    「世间无常、国土危脆」主说无常；苦与无常何关？无常故苦。从无到有则有生相，有生则有老病死：有生即有苦苦（性苦）；诸法无常则有灭相，灭相即有坏苦（健康之法灭去，坏苦生）；诸法不断生生灭灭，即有行苦（粗重相）。老子云"吾有大患，为吾有身"，因有四色身，乃有相续之苦。四大之苦，为修行人观照之所缘境，以破除对色身之执取。

    四比丘论苦公案 #

    《法喻譬喻经》载：佛世有四比丘讨论世间最苦之境：一说淫欲，一说嗔恨，一说饥饿，一说惊怖，争持不下。佛问其故，答以实情。佛言皆错：世间最苦者是色身——有色身，一切苦随之而生；有身故有淫欲、惊怖、忧愁、恐惧。

    佛更说过去因缘：久远劫前林中四兽——鸽子（淫欲）、蛇（嗔恨）、鹿（恐惧）、乌鸦（饥饿），各执己见争论最苦；一旁打坐比丘告言：最苦是因有身，有身故有爱着贪着。佛言：昔日比丘即我，四兽即汝等；我过去已说，汝今犹争。四比丘由此体会四大为根本苦，证阿罗汉果。

    六、四大之空 #

    空者，无真实性，诸法无自性。真实性者，生起不需条件因缘、能独立存在：如桌子不需木工加工即自存；若此身不需宿世颠倒妄想、不需父母和合即突然出现而恒常不变，方名真实。然"法不孤起，仗缘方生"：一切有为法皆业力所生，循业发现；业本身生灭无常，故缘起即无常、缘起即生灭，因无常而见空。色身之显色、形色、青瘀、败坏、腐烂等变异，说明此四大假合之色身是业力所现之影像；业力有生灭，影像即有生灭，无真实体性。此是粗分观察。

    细分至于根源：无常亦不可得，四大体性皆虚幻。经云"一水四见"：同此一杯水，人道见为水（湿性），饿鬼见为猛火（暖性），天人见为琉璃（坚性），鱼见为空气（动性）。同一种水，具坚、暖、动、湿四性而变来变去，可知其无真实性。地水火风所谓基本元素，一经分析，皆虚幻无自性，循业发现：有此业力，见此境界；无此业力，不感此境。四大所成之色身，更无真实性可得，如梦境中之色身，除能梦之第六意识外，一切皆不可得，只是随业力所现之影像。故四大苦空，空即循业发现之义。

    七、身为苦本（《大智度论》） #

    《大智度论》问曰：「何以不问无恼无病，而问少恼少病？」圣人答：「圣人实知，身为苦本，无不病时。」既有四大色身，即有无常病、有苦；从生即集一大苦聚。舍利弗生病不能行走，令人抬往闻法，然心自自在——色身是宿世杂染业力所成，故有无常病；圣人尚且如此，凡夫应如实接受。有病属正常，有病须治，内心不须添烦恼。佛前所求，只求少病少恼，不求无病无恼。世间初学佛者，念经布施后生病，信仰即动摇，是不知如是业召感如是果；业力不多给一分、不少给一分，病得恰恰好，故不必求无病无恼。

    「是四大和合而为身，地水火风，性不相宜，各各相害。」四大相生相克，热则失平衡须开空调，冷则须保暖；热冷交替，即无常苦恼。四大体性本不兼容，因业力故不得不和合一处，故当渐渐接受四大变化，生病本是常态。

    「譬如疽疮，无不痛时，若以药涂，可得少差而不可愈。」四大无常病如疮，涂药可暂舒，不可能痊愈，因本质即是无常。故不求无病无恼，只求少病少恼。

    「人身亦如是，常病常治，治故得活，不治则死。」人身有病正常，饥食困眠皆属四大病范围。学会接受认命，有病即治；欲永离四大病，则往生极乐，一劳永逸。

    「以是故不得问无恼无病。外患常有风雨寒热为恼故，复有身四威仪，行住坐卧，久坐则极恼，久卧久住久行皆恼，以是故问少恼少患。」风雨寒热之恼，四威仪久坐久卧久住久行之恼，皆本质是苦，故所求务实，但求少恼少患。

    四大之种子在心：出现何种四大色法，取决于阿赖耶识中有何种种子；色身存在，即业力不断释放支撑。善业力释放则四大调和轻安，恶业力释放则痛苦。苦乐皆业力释放之正常范围，视因地种子而定；今生得此色身，即因地不清净，果地之果报亦不净苦恼。故面对色身，但求少病少恼。

    圣人不抗拒无常：圣人有有漏果报身，然坦然接受，不为四大之苦增添烦恼；凡夫执无常为常、生贪爱执取，偏偏无常败坏，故苦上加苦——众生之苦根源即在于此。观察至此，当少爱少取，方能渐渐远离生死。

    八、食厌想：观身不净 #

    「食厌想者，观是食从不净因缘生。」借饮食不净观，看色身之本质。

    「如肉从精血水道生。」肉为精血和合而生；年长肌肉萎缩消融，人渐矮小，皆精血和合之故。「是为脓虫住处。」肉放久即生虫，色身亦然；死后无人料理，肉腐生虫，钻来钻去，即众生认知之可爱色身。「如酥奶酪，血变所成，与烂脓无异。」肉食本有腥味，须调味烹煮以去之；动物食腐肉以为恶，众生食肉实与动物无异，不过会包装而已。古德言：色身置于大海洗涤，洗至一粒沙，亦无一处干净。

    「厨人汗垢，种种不净。若着口中，脑有烂涎，二道流下，与唾和合，然后成味，其状如吐。」一团烂肉入口，涎唾和合即成美味；嚼之觉香，吐之即厌，其状如吐——不过皮肉包藏，不见其相。若人透明可见，饮食之相无人愿睹。「从腹门入，地持、水烂、风动、火煮。」腹中四大维持运转，如釜中烂糜，滓浊下沉、清者在上，如酿酒：滓浊为屎，清者为尿。享受在上，消变在下，兵分两路。健康饮食即可，不必于其上生染着执取，此亦障往生之因。

    「腰有三孔，风吹腻汁，散入百脉，与先血和合，凝变为肉。」食入之物流变血肉，从肉生脂、骨、髓，从是中生身根。「从新旧肉合生五情根，从五根生五识；五识次第生意识，分别取相，筹量好丑；然后生我、我所心等诸烦恼，及诸罪业。」此即十二因缘流转过程：因地颠倒召感不净果报；五识取境不带分别，第六意识分别筹量好丑，生我、我所烦恼造罪。欲界众生不得不有饮食欲、男女欲，追逐取着，长养六根，满足我、我所；我我所复生烦恼造罪。纵持五戒清净，此执取即感应下一份生死。

    「观食如是本末因缘，种种不净。知内四大与外四大无异，但以我见故，强为我有。」受用果报体时当自防范：六根对六尘，勿取随形好，勿施设名言，勿堕爱取有。执取心即召感下一果报之因。如经典所载沙弥，贪奶酪之味，堕为奶酪虫。贪念虽小，当下即染污全部身心；就召感生死而言，贪一分与贪一片本质无异，仍在轮回。临终"已放下九十九分、余一分未放"之想，不切实际。

    九、五阴无我 #

    前观色身偏重，今就色、受、想、行、识五蕴观"无我"。“我"之定义为主宰义：不被一切法主宰，亦能主宰一切法；恒常不变。若此身心世界可自主，即不应病、不应老、能随心支配一切。然仔细观察，色受想行识中觅不到恒常不变之"我”；若能主宰，应永远快乐，而众生无时不苦——苦故无我，内心不断变化故。

    凡夫执五蕴为"我"，有二种计执：

    即蕴计我 #

    执五蕴当体即是我。执"色"即我者，多为断灭见：认为色法主导心法，人死如灯灭，生命只有一次；虽或行善，难免造罪，因不信来生。然色法不能主导心法——古德如虚云老和尚年逾百岁而眼神炯炯、六根明了，即色法不主心法之证。执"受"即我者（“我受故我在”）：受有苦乐变化，前后不一，不合"我"之定义。执"想"即我者：想法胡思乱想、夜梦纷飞，飘忽不定。执"行"即我者：行蕴念念迁流，推动色受想变化，本身即是变化，云何是我？执"识"即我者：八识心王亦是虚妄。故即蕴计我，五蕴各各非我。

    离蕴计我 #

    离蕴计我，谓离开五蕴另有一恒常不变之"我"存在——此亦无实证可得。

    结语 #

    本讲深入第一觉：明世间国土唯心所现、业力为本之根源，观别离、法性、合会三行相；复释「四大苦空」（三苦、循业发现之空、身为苦本、食厌想不净观）与「五阴无我」（主宰义、即蕴离蕴计我）。无常观建立，厌离心方有所依；此一觉立，后之断恶修善、发菩提心方能成就。
