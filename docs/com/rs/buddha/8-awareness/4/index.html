    离蕴即我·四谛总观·第二觉多欲为苦

    2026-10-21 Atom.X

    《佛说八大人觉经》讲记 · 第四讲

    一、承前回顾：知见贵在清晰 #

    前三讲已详释「世间无常，国土危脆，四大苦空」之缘由。修学之初，正见之建立须清晰彻底。知见若模糊，则修行多在空转，虽费时力，难有感应；故首重知见，方能不走弯路。

    二、外道邪见：离蕴即我 #

    五蕴皆空，外道计我有二：一为「即蕴即我」，已于前讲破之；二为「离蕴即我」，谓五蕴之外，别有恒常不变、有自性、不生不灭之「我」。五蕴有老病死，而此离蕴之我独无。譬如人住屋中，屋坏可另得新屋；屋有生灭，屋中之人则不变。此即离蕴计我之见。

    此见与今人学大乘之「自性执」相类。闻「何期自性，本自清净」，便于心中拟一佛性之影像，或虚空、或光明，执此相为佛性之实。初学带相观空，原无不可；然若执此相即是佛性，即堕自性执，与离蕴即我同病。依此见，则谓谁在轮回？即是离蕴不变之「我」在轮回。然离蕴之我究竟何相？外道不能言。盖所言任何相貌，皆不出五蕴范围；离开五蕴，别无「我」可得。

    三、偈颂破我：无我观之修法 #

    《中论》偈云：

    若我是五蕴，我即为生灭；若我异五蕴，即非五蕴相。

    前句破即蕴即我：我若是五蕴自体，则同五蕴而有生灭，失其常一。后句破离蕴即我：离蕴之我，即非五蕴之相。外道或谓五蕴之外别有第六意识为我，然佛陀只说五蕴，不说第六蕴，此相乃妄情捏造，如龟毛兔角，实不可得。

    修无我观之法：先辨明「我」之定义与相貌，再以此相貌遍观色受想行识身心世界，寻觅有无此物。譬如寻人，先认照片，再至闹市遍寻；寻之不得，渐契无我之理。

    「我」本无定义，皆凡夫依妄情捏造。初生即有俱生我执，及长，分别我执随第六意识转强。家庭、学校、社会之教育，皆在肯定与强化此「我」。世间宗教或以神主宰万物，或以神明为依归，皆系凡夫困厄中所造，无一能说无我；唯佛陀说生命真相为「无我」。未有佛陀出世，无一人能出三界；世间聪明者纵想出离，亦不知如何出离。修无我观者，先立根本知见：没有一个真实的「我」在修无我观。若有实我修观，修至无我，则诸佛犯杀生罪矣。实则「我」自始未曾实有，唯第六意识妄情作用而已。

    四、公案一：尼犍子问佛 #

    佛世有外道尼犍子，见比丘言谈威仪庄严，问其师承。比丘答：随净饭王太子出家成道之佛修学，佛教导观察色受想行识无常、苦、空、无我。尼犍子斥「无我」为邪见，邀同见之人往佛所辩论。

    至佛所，尼犍子问佛：汝教弟子修无我观，然否？佛言：然。尼犍子谓：世界一切皆因有我，我能创造万物与思想，云何言无我？佛以喻答：大国之王，于有罪者能罚，于有功者能赏，可否自在处理？答：能。佛言：能作主宰者，即有自在力；「我」之定义即是常一主宰、有自在力。汝主张色受想行识各有其我，则此我应具此力。然汝能令此色身不老、不病、不死乎？能令其随心苦乐乎？尼犍子沉思良久，不能答。佛言：五蕴既不能主宰，则无「我」之自体。尼犍子遂承认无我。

    五、公案二：龙树菩萨破有我论 #

    《大智度论》载，龙树菩萨以善巧辨才破有我论。有我论者喻云：身中有我，如国王统率将军，将军指挥军队；我心识为将军，色身为军队，另有「我」为国王主导心识。

    龙树菩萨破之：若心识之后有我指挥，则我后复须有我，辗转无穷；若无须如此之多，则皆不须，但以心指挥身足矣。外道谓我是一法，心是一法，身是一法；龙树反问：我之体性离此一念心，为有知觉？若无知觉，则不能支配有知觉之心以思惟造业；若有知觉，则何须再立此心，直以我指挥身、受用五欲可也。世间一切法不出有情无情，无第三类，故主宰之「我」实不存在。所谓「我」，不过执着六尘妄影之心，误认其恒常不变而已。

    六、无我三观：当体、离体与因缘 #

    破五蕴计我，有三观法：一观当体，二观离体，已如前辨；三观因缘。静坐中思惟：色受想行识皆因缘和合而有，假借因缘而生；离此因缘，别无恒常不变之体性可得。观之既熟，即知五蕴无我。

    七、第一觉之次第：由粗至细 #

    第一觉四句，能观所观各有不同：观国土，能观之智是无常，所观是国土；观四大，能观之智是苦空，所观是四大；观五蕴，能观之智是无我，所观是五蕴。然无常、苦、空、无我三种智慧，实通于国土、四大、五蕴及一切有为法；经典所以次第安立者，随修行者心之粗细：初修心粗，故先观粗境——国土无常；心渐细，乃观四大苦空；心最细，方观五蕴无我。无常故苦，苦故无我，总观则通用。

    利根之人，由观国土之无常，觉其不可主宰，遂回光返照，悟「我」实不可得；钝根之人观国土，每于否定外在之际，反不断肯定内在之我。故佛于「世间无常，国土危脆」之后，续说「四大苦空，五阴无我」，正为杜此弊。

    八、念佛人当省：放下须落实于无我 #

    初学与念佛之人，多能感受世间无常，却少能体会四大苦空、五阴无我。厌离欣求之际，常以世间爱憎取舍之心行之：厌离娑婆、欣求极乐，皆围绕自我而转。此种心与平等广大之菩提心不相应，临终亦难相应。须知「我」是根本无明、生死之根；无常苦空只是善巧方便，关键在「无我」。放下者，须在无我处放下，方是究竟。

    九、总观苦谛：生灭变异，虚伪无主 #

    前三法为别观，此句为总观：国土、四大、五蕴，一切有为法皆苦、空、无常、无我。生者，本无今有；灭者，暂有还无。变者转易，异者刹那无常——现前身心刹那迁流，欲描述当下，其境已过。虚伪者，幻有之义：云随因缘而变，身需饮食滋养，皆无真实不变之体。无主者，无我之义：所谓「我」，不过假名。故「生灭变异，虚伪无主」为苦谛之总观。

    十、集谛之观：心是恶源，形为罪薮 #

    「心是恶源」属集谛，指爱烦恼：心中有爱即有恨，得之则爱，失之则恨，由此起惑、造业、受报。所贪之境可爱，所憎之境可恨，心于境上造罪，遂召感世界苦空无常无我。

    「形为罪薮」指见烦恼，要义在身见（五利使之一）：认色身为实有、为我所。他人之身病伤，与己无涉；己身一病一伤，苦痛剧增，此即身见。由身见生爱着，顺境起贪，逆境起嗔，遂造杀盗淫妄之罪。「薮」者集聚：色身集聚诸恶，心造业而后受种种苦。此二句明苦果产生之因，为集谛之观察。

    十一、色心不二：修行莫在枝末 #

    讲说之时，可分别心法与色法；立知见之际，不可判然切开。业力是心的功能，色身乃色心和合之体，其中含藏过去业力与未来造作之无明冲动，故不随死亡而了。若不见色心不二，修行即落枝末：或谓心地用功、不必着相，实则仍贪着自身色法——布施唯口随喜，不舍身财；或执出坡劳作不如独坐用功，实是守护色身、恐身受苦。凡此皆知见未彻。

    欲界众生不得不受用欲以滋养色身，然须时时防护观照。在家人贪染尤甚：晨昏对镜，明知愈照愈老，仍照之不辍，守护色身未尝稍舍。趁身尚健，急急听经闻法、念佛修观；勿待色身将坏方思用功，则悔之无及。

    十二、四谛观察：如是观察，渐离生死 #

    「如是观察」属道谛，「渐离生死」属灭谛。修行先须擒贼先擒王：未上路者，起烦恼辄归咎于境界、他人；真上路者，方知苦痛皆由内心无明烦恼。故先察己最粗重之烦恼——十恶业中何者最常造，此即集谛观察。

    次修止观，以苦谛对治最贪爱之境：所贪境界本为常乐我净之错觉，实是无常、苦、空、无我。观察既熟，则不被境界所转，不复认贼作子，渐知所贪爱者实是令我轮回之境。

    净土行者，先观苦集二谛，生厌离心，了知烦恼为召感娑婆之正因；次观灭道二谛，缘极乐依正庄严，生往生信心。净业成熟，临终随净业往生，渐离生死。

    十三、入道要门：无常无我觉之总结 #

    第一觉「世间无常，国土危脆」为无常无我觉，是入道要门、发菩提心之基。第二觉至第八觉皆以此为核心，诸觉悟之资粮皆从第一觉生起，是为八正道之首——正见。有此智慧，方能如实观察、渐离生死；无此，则念念爱取有。

    心之体本一：迷则为恶源，悟则为解脱源。如《起信论》一心开二门：以佛法转心，则一切善源、解脱源从此而生；继续颠倒，则一切恶源从此而起。「一切业障海，皆由妄想生」；「诸佛正遍知，皆从心想生」，就视此心如何而用。

    十四、第二觉知：多欲为苦 #

    多欲为苦；生死疲劳，从贪欲起。少欲无为，身心自在。

    第一觉以闻思建立正见；第二觉以下明修行方法，含断恶、修善、发菩提心。第二觉属断恶：修行先自利，自利先断恶，断恶即减少内欲，名「常修少欲觉」。

    此一条依四谛，分流转、还灭二门：多欲为苦（现世苦）、生死疲劳（未来苦）、从贪欲起，是生死流转门；少欲无为、身心自在，是还灭门。

    欲即希望，财色名食睡诸欲，本质苦多乐少。欲界众生不得不受用欲——有此正报身心，必有相应依报令其受用；问题不在受用本身，而在受用时及受用后不加观照防护，令欲辗转增盛，遂造罪业，爱取有而轮回。生死疲劳者，指无尽轮回之疲劳，非止一生。当立正见：受用欲是为成道业、利众生，不于相上生贪；贪则贪真实功德，勿贪生灭杂染之法。

    十五、欲之苦相：求时、得时、失时 #

    龙树菩萨偈云：

    诸欲求时苦，得时多怖畏，失时怀忧恼，一切无乐时。

    求时苦：学生求功名，起早贪晚，忍玩用功；商贾求利，绞尽脑汁，勾心斗角，费时费力，未得之前已多苦恼。得时多怖畏：功名易失，唯恐人超，身心绷紧，不敢松懈；财富难守，须运转不辍，稍停即败，唯一之乐不过数钱片刻，旋即忧惧。失时怀忧恼：福报享尽，权势地位一失，痛苦尤甚；富贵者失势，或觉尊严尽失，乃至自绝。天人临死，以神通知将堕恶道，起大怖畏——或依余福本可不堕，然怖畏忧愁加持其心，临终反堕三恶道。爬得愈高，愈是担忧。在家出家，凡为名利者皆然。

    十六、事欲与烦恼欲 #

    《瑜伽师地论》云：

    又诸欲自性略有二种。一者事欲。二者烦恼欲。事欲有二，一者谷彼所依处，谓田事。二者财彼所依处，谓金银等事。烦恼欲者，谓于事欲随逐爱味。依耽着识发生种种妄分别贪。

    事欲者，对事与物之贪着，如衣食住行，为欲界众生之必需，偏于动物性，尚属合理。然事欲之初起，本由烦恼欲推动；推动之后，随之而来之妄分别烦恼欲，方是增长生死者。可畏者即此烦恼欲：受用事欲时，起苦乐二受，遂生种种虚妄分别。如食榴莲：第一口生乐受，即分别其产地、价值，复冀乐受再现，贪烦恼随之而来。受用事欲时，须防此烦恼欲；不加以观照，事欲即引生妄分别贪，增长生死轮回之苦。

    十七、烦恼欲之过患：妄分别与赋予意义 #

    众生对事欲之所需实少——食不过三碗，睡不过一床；而对烦恼欲之需求无穷无尽。多非真需，乃藉以证明自我价值。同一事欲，一经赋义，面目全非：一果之馈，因分别而生烦恼；一物之赠，因赋义而成情锁。事欲之外，更杂人我爱憎种种价值观念。

    烦恼欲皆自找、不必要，然一旦生起，即自锁其中，令事物失其本来面目。众生之爱，多系满足自身身心之需，非无条件之真爱；唯佛菩萨之慈悲，方为真实之爱。

    结语：合掌回向，愿共成道业。
