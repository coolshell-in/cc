    名山寺庙参访记

    2026-09-20 Atom.X

    由于2025年终的个人总结，我立下目标在今年要深度学习和体验佛法，到寺庙参访是必不可少的部分，从年初到目前已经在3个寺庙挂单（住宿）做义工，并跟着寺庙时间表参加早晚课和法事活动，按照世俗知见的标准看，这三家各有特色和优势劣势。

    如同商业和教育领域的特征，庙不在于知名度和规模的大，而在于精。

    优势就不说了，因为世俗民众对寺庙和僧人的期待本来就高，犹如对大学教授的膜拜，既然有那么大的头衔，就应该是高知的样子和科教成就。

    单讲一下这里某些劣势或不合理的部分，一些经典案例。

    洗碗 #

    我们过完斋后，被小组长分配去洗碗，他指挥我们弄了三大盆水，有一个简易的操作流水线的程序，第一道是把碗放到有清洁剂（洗洁精和茶籽粉）的盆里去掉油渍，第二道碗放到清水中清洗去掉清洁剂和明显的污垢，第三道过完清水就算洗完了；最后一道，拿干毛巾擦干，然后送到消毒柜里烘干，这是他们的一个标准作业流程SOP（stander operation procedure）。

    如果是严格按照寺庙戒律过斋，以上的SOP是完全没问题的，我双手双脚赞成，因为标准合格的僧人吃得很干净，而且还要最后倒一些开水把碗刷一遍喝下“洗碗水”，业内称为“惜福水”，或者拿馒头把碗里的油渍搽干净吃了，但是。。。

    这里有前提条件的，凡事总是要根据实际情况做特殊处理，在我这次来访的一个寺庙里，多半的碗里有不少饭菜渣滓和汤等。这当然不是僧人留下的，而是居士，以及更多来自外面的访客，因为该寺庙允许未经任何培训的访客吃饭，那当然就和外面社会人是一样的情况，其中不少居士和义工也并未经过合格培训，虽然比普通的访客好很多，没有糟蹋浪费粮食，但也达不到僧人的严格标准，碗里总会留下少了食物渣滓或汤。

    于是看到这种特殊情况，我赶紧到第一道之前，又增加了一道“清理碗里的厨余”，我找到一把刷子，正干得欢，并特意告诉负责第一道清洗的师兄，必须过我这一关之后，他才能拿到碗。

    但是，这时候小组长来了，几乎大声呵斥，说“没必要浪费水”，我回复他“碗里有这么多食物渣滓和汤，必须先清理掉”，他说“这是师父定的标准作业流程”，我说“俺在5星级酒店受过职业培训的，按照较高的标准清洁”，他回复“这里没有服务员，5星级有服务员”，这就属于诡辩和离题了。

    小组长拉着我到最后一道，递给我1块毛巾，分配我擦完，并说“看洗得干净么？”，我没好意思再讲“我比你们，比师父都更专业”，毕竟我还没有被任命为管理者并可以发号施令。

    我也认同一个道理，在军队里，即使指挥官下达了错误的指令，士兵也要去执行，哪怕带来很惨重的损失。士兵被无谓地牺牲，指挥官承担责任，佛法叫因果。

    贤能 #

    实际上，我对这家寺庙的干净整洁程度，应该是我参访的3家和其他见过的寺庙中做得最好的，从绝对清洁能力上看，他们的分数最高，已经达到了70分，依然有很大的提升空间，也就是本来可以做到90分以上，剩下的10分是因为硬件基础设施（硬伤）的设计、材料和工艺达不到高标准要求，再怎么努力也枉然。

    只要按照我的方法，其实也不是我发明的方法去做，任何能用点心的人都可以做到，但是大多数人做不到，因为他们不用心，用世俗的话讲“不用脑子，没有责任心”。

    完全根据上级领导的指示，生搬硬套固定不变的模式，遵守陈规陋习，大概就是以上的洗碗小组长，这种落后的人比例非常之高，我估计超过8成以上，不超过1成是优秀者，还有1成多的纯粹就是作死捣乱分子。

    很多日常工作都是如此，包括清洁房间、厕所、外面道路，以及办公室里的脑力工作更是不计其数的类似糟糕扯淡状况。

    为什么会这样？两方面原因，首先是上级管理层，师父是否慧眼识别哪些人才，并委以重任，这是选人和管理的问题；其次才是执行者本人的问题，也就是小组长和下面具体干活儿的人，这些人干不好或不好好干，一方面是自己在造业，能力没有持续提升，另一方面证明了管理层不合格，师父不行，管理者是终极原因。

    别以为一出家就惊为天人了，高僧大德都自称凡夫，遵守佛法完美，但平行宇宙里还有并行的世间法的另外一套，包括出家人和在家人都感到隔行如隔山，各行业和专业工种千差万别，不懂世间法里的很多门道和规则是很普遍现象。

    日常的工作（出坡），仅仅一个房屋清洁为例，最顶级的清洁工需要这些条件：数十乃至百件工具，光拖把就好几种，材质包括海绵、棉布、搓板类型的等等；吸尘器根据功率和口径还分了好多种，包括地面、沙发和床上、窗户和家具缝隙用途的最小型吸嘴的等等；

    清洁剂有10多种化学品，用于厕所、厨房、客厅、卧室、办公室等不同空间，仅仅厕所里就有专用于“玻璃、马桶、便池、洗手台、洗衣机”等不同设备设施上的清洁剂，每一样都是专业的，包括用量，配水浓度等要求都不同。至少要读懂说明书和按照规则使用，否则会出问题的，甚至是严重的问题，例如新闻报道，每年都都有很多小孩误食了这些化学品中毒，如何存储保管都是专业活儿。中国有多少比例清洁工会合理使用化学品？估计比例不超过1成。

    我还试过到不同的单位查看洗衣机，包括家庭、学校、企业集体宿舍、旅馆、寺庙等，9成以上的人都不会清理老一代洗衣机的“垃圾槽”。

    我每次洗衣服都会动手扣出来，把纱网袋子的已经发霉变黑变臭的一大坨东西抠掉，并用刷子把它们都洗干净，再用刷子和纸巾把垃圾槽里可见的地方都擦干净，还有滚筒里面看不见的部分，只能用洗衣机专业清洁剂，水泡上至少半小时，然后再开筒自洁模式清理，这些多个程序的复杂操作，让大多数人都无法胜任，那些受过高等教育的人会操作，但是他们的生活习惯懒惰邋遢，也不会动手清理，这就是现状。

    寺庙里，很多人有洁癖但是从来都不知道要清理洗衣机的“垃圾槽”，当然现在用最新款的滚筒洗衣机，免除了手工清理垃圾槽，而且筒自洁模式也更自动化，不过还是需要人手动开启，也许未来一定会出现那种人工智能的洗衣机和各种家电，里面的传感器会实时检测健康和卫生状况，并自动启动清洁和消毒。

    但过度科技现代化，结果就是培养了更多懒惰和无能的人类，不需要脑力和体力，人类就被当作宠物养，越来越废材。

    训练营 #

    按照目前的科技发展趋势，人类必然会废柴比例越来越高，欧美等发达国家就是如此，因此我提出创建“训练营”，故意设计那种原始的生活环境，让人进去体验和训练，还要通过数十乃至上千道测试，只有过关的人才算是合格的人类，否则就是无法生活自理的废材，在未来都要被淘汰的人类。

    为了提高人类智商，训练营中必不可少的是“数字戒毒”，也叫做戒网瘾并提高专注力，包括记忆里和逻辑推理等思维能力，所以可做的非常多。

    按照已经上市的科幻片和科幻小说的描述，未来的穷人会被大量机器人替代，有良知的政府和富人就通过税收给穷人提供低保，但他们没有多余的钱训练以上所述的生活自理技能，只有富人的后代才有资格条件去提升自己，犹如欧美那么多穷人都是胖子，富人更苗条，减肥药和训练需要很多钱，而吃高热量的食品和糖水只需要很少的钱。

    以前穷人没得吃，饿的皮包骨头，现在乾坤倒挂就是这样的场景，魔幻且现实。

    智商 #

    这里唯一的问题是人的智商，曾经很长时间我理解不了的是，寺庙和公益组织为何聚集那么多缺乏记忆里和思维逻辑的人，俗话说得很难听叫“低教育低智商”。

    我反对“教育决定命运论”，类似我这种主要靠自学的人还蛮多的，并未受过体制内良好学校教育，为何我们这些自学的人，无论普通的体力劳动的清洁工作，还是数学、编程和英语等脑力劳动都可以干得很好，并获取高收入？

    这种能力是向下兼容，也就是高级脑力劳动者也可以干普通体力劳动，但是只掌握普通体力劳动能力的人，无法向上兼容高级脑力劳动，让只会冲厕所和扫大街的人去编程是不可能的。

    一方面是天赋，更多是后天的训练，我自己就是活生生的案例。

    所以，寺庙和公益组织是有责任训练人的，而我们看到他们只会宽容，缺乏工作标准，干好干坏都一样，甚至任用根本不合格的人做管理者，结果就是毁坏自己的口碑。因为人们的要求越来越高，对非赢利机构也会挑毛病，即使不追求进步的人，也会对别人提高要求，这叫符合人性的“宽于律己，严于待人”。

    论缺人吗？中国世界第一的人口，除了高科技的少数部分，缺好的管理者，其他任何一个领域都不缺人，最不缺的是基层的执行者，就是劳动大军最多。

    东方的管理体系是金字塔结构的自上而下的，上面的领导者有统领一切事务的绝对决策权，所以底下人干出什么水平，就能看出上层人物的水平了。

    我们经常在修行圈听到人们谈论“德行”，有德行就一定能把活儿干得好吗？似乎未必，我见过很多老好人，活儿干得稀烂，让同事和上级都不满意，背后说这人“德行好，但能力很差”，勉强不要辞退，留着混日子过，这说起来就很有人格侮辱的意味。

    所以，我也从来没想过什么“修行、德行”之类的，这些概念与我无关。

    我崇尚科学和工匠精神，格物致知，通过把事情做到极致来达到人生的种种成就，无论是经济收益或荣誉身份，这是我存在的价值和理由。

    我并不好为人师，去主动教谁谁去做，说多了显得我傲慢，我只干，让其他人看到，如果价值得不到认可，很简单，那就离开吧。

    现实中，无数次有人教我做人和做事，我来教你，我总是感到好笑，心里暗想“又一个班门弄斧的”。他们不会看人简历，也不会预先了解现在面对的是怎样一个背景的人，不知道这个人拿了多少个中国第一和行业天花板。

    尽管每次遇到一个新人，只要确定对方是愿意对话并无恶意的情况下，我都会把个人网址发给他们，上面有最全面的我个人项目经历、社会活动、教育和技能背景介绍。但他们大多数人也不会看，因为都刷抖音去了，没人会看文字。

    迄今为止，在我不怎么使用的微信朋友圈里，至少存着1000个人，有个人网址和如此详细履历的人不超过10个，一般程序员有个人网站，其实并不是需要多强的能力，小学生都可以做，不一定要像程序员一样自建网站，用普通的博客平台也行啊。

    而是大多数人都没有用心，在这样一个剧烈变化的时代，社交也要节省时间提高效率，让陌生人15分钟了解我们的大半生经验或阅历，这是一种单向的信息传递，我变成透明人了，但是对方是什么背景，过了3年我也未必知道，或者需要5年通过各种道听途说才弄清楚一点点，不过我不关心这些。

    传统社会里，很多人认识了3年，连他工作背景和有什么技能都不清楚，更何况介绍什么机会给他呢，这种受过高等教育，无法把自己介绍清楚的人太多了，占据了6成以上，呜呼哀哉！

    所以筛选并训练人太重要了，寺庙尽管广开佛门，但宽进严出。寺庙在现实世界中的资源有限，在世间法里不可能普度众生，法师（凡夫）的个人时间精力有效，寺庙房产面积有限，粮食和水电也有限，处处都要珍惜不可浪费，但实际他们在违背祖训，以“普渡众生”之名，行“挥霍浪费”之实，把太多资源都浪费在那些朽木上。

    但同时，他们的做法也没有错，在佛法的神性的平行宇宙里，朽木是可以雕琢的，并有机会成为栋梁之才。这种更高维度的思维和智慧，我这凡夫不懂，只能根据经书略有理解。

    根源是，我这凡夫（不够好高骛远）看不到极乐世界，只会盯着地上的现实世界看，我每天只想着过好现在这一生，过去的既往不咎，也不会想太多未来，”谋事在人，成事在天”吧。
