    Tai禅师论佛的果位阶层

    2026-10-20 Atom.X

    Taiguanglin 禅师自述为「再来人」，来中国修行的韩国僧人，其官网有「投胎前的法身名号」「再来人传法者」等提法，《坐禅问答录》第一章记其修行历程。

    以下内容依据Tai禅师的《坐禅》其中相关章节内容摘录。

    依据分三层，全文据此标注：

    • 原书：第一章总论第 01—03 节讲三界二十八天，第 07 节讲五乘佛法；第二章第 04 节、第三章第 03 节、第四章讲功夫次第。
    • 佛教通说：天层名称与禅定的对应关系属经论通说，原书采用这套通说。但「某品天对应某段功夫」的细部判位无法逐条核实，凡属通说此处都标明，对照原书时请以原书为准。
    • 第三方图：网传「五乘佛法」结构图出自 B 站 UP 主「Taiguanglin讲禅修」的视频（非官网内容），自下而上标注：初禅、二禅、三禅、四禅（色界）→ 八定 → 无量空入处定、无量识入处定、无所有入处定、非想非非想入处定（四无色定·无色界）→ 九次第定 → 受想定。该图对应的原书章节是第一章总论第 07 节「五乘佛法」，不是「第 12 集」（编号来自视频分集）。

    阶层—功夫—天层对照 #

    书中阶层功夫对应天层（通说）
    人天乘福德法修福修德、做人做事，积资粮欲界人道、六欲天（通说：修十善业生天）
    声闻乘离苦法·第 1 阶欲界禅定：净化身体、打通筋脉，灭文字妄想、收摄六根仍在欲界（通说称五趣杂居地），未离欲，不感色界天身
    声闻乘·第 2 阶初禅（离生喜乐）色界初禅三天：梵众天、梵辅天、大梵天
    声闻乘·第 3 阶二禅（定生喜乐）二禅三天：少光天、无量光天、光音天（玄奘新译极光净天）
    声闻乘·第 4 阶三禅（离喜妙乐）三禅三天：少净天、无量净天、遍净天
    声闻乘·第 5 阶四禅（舍念清净）；原书合前五阶称「五禅」四禅诸天—— 名单有楞严、俱舍两系，见下节
    罗汉乘解脱法原书：「声闻如何修无色界定成为罗汉」「罗汉乘解脱法有无色界四禅」无色界四天：空无边处天、识无边处天、无所有处天、非想非非想处天
    菩萨乘六度法灭九种分别心（原书称此段为「罗汉九禅」）已出三界，不在二十八天之内；原书另提「去了兜率天跟弥勒菩萨学也可以」
    佛乘寂灭法灭十一种妄想；菩萨十地＋等觉地共十一地超越三界二十八天

    原书第 07 节的五乘次第为「人天乘福德法、声闻乘离苦法、罗汉乘解脱法、菩萨乘六度法、佛乘寂灭法」，与传统「人、天、声闻、缘觉、菩萨」五乘不同——原书不设缘觉乘，另立罗汉乘与佛乘。

    分层说明 #

    欲界禅定这一阶，原书定位最特殊。 它不对应任何一层天，因为功夫还在「净化身体、打通筋脉」阶段，淫欲、食欲未根除，仍属欲界散地。原书的相关表述是「不管用什么办法，先打通全身筋脉是第一步！」「到这里，才算进入了欲界禅定——是禅定的第一个阶段」「世上没有绕过身体直接修意识的方法！」。通说把欲界（含六欲天与人、阿修罗、畜生、饿鬼、地狱）合称「五趣杂居地」，是散心之地而非定心之地。

    四禅才是真正跨入色界。 通说认为色界诸天全部由禅定深浅决定：修劣、中、优初禅分别感生梵众、梵辅、大梵；二禅感生少光、无量光、光音；三禅感生少净、无量净、遍净。四禅则分凡夫所居、外道所居（无想天）、三果阿那含所居的五净居天三类。这一点对作图很关键：同为四禅，果位可以完全不同——凡夫与三果圣人同处一层天，差别在有无无漏慧。

    无色界四天对应四无色定，一一对号。 空无边处定感空无边处天，识无边处定感识无边处天，无所有处定感无所有处天，非想非非想处定感非想非非想处天。网传结构图正是按这个顺序排列四无色定。但通说反复警告：这四定属世间禅定，未断无明根本，定力消散仍堕轮回。

    「受想定」是网传图上的分水岭。 它排在四无色定之上、属「九次第定」的最后一环。但这一格的标注需三处留意：

    1. 图上 OCR 只见「受想定」，未见「灭」字，无法排除识别丢字，建议对照原视频画面复核；
    2. 通行术语是「灭受想定」，它是「灭尽定」的异名（因加行偏厌受、想二心所而得名），玄奘新译多径称灭尽定。「受想定」不是通行写法；
    3. 原稿说它「不感生任何天界，是出三界之关键」，此说不确：《俱舍论》卷五「此定所招何地几蕴？唯招有顶四蕴异熟」，即仍在三界最高处感果。判为「出三界之定」是大乘唯识的说法（无漏、非界系），有部则判有漏、有顶地系。可确证的是：此定唯圣者能起，以「现法涅槃胜解」入，「最为寂静，极似涅槃」。图上宜注「两系判摄不同」。

    三个容易画错的点 #

    1. 「九次第定」≠「三界九地」。 九次第定＝四禅＋四无色定＋灭尽定，是修行次第；三界九地＝五趣杂居地、离生喜乐地、定生喜乐地、离喜妙乐地、舍念清净地＋四无色地，是空间与定境安立的坐标。两者数字都是九，但第九位不同：九次第定的第九是灭尽定（依有顶），三界九地的第九是非想非非想处地。前八可对应，第九不可。一为「定」、一为「地」（断惑所依），图上别混标。

    2. 四禅诸天的名单有两系，色界总数有三说。 详见下节——原书用的是楞严系，原稿细表用的是俱舍系，两者不一致。

    3. 天层是「果报坐标」，果位是「断惑坐标」，不能一对一。 五净居天是三果阿那含所居，阿罗汉已出三界、不居任何一层天，菩萨、佛更在二十八天之外。所以「凡夫—阿罗汉—菩萨—佛」这条果位线，与「欲界—色界—无色界」这条天层线，只在「声闻乘」这一段重叠，往上就分开了——画成两条平行线比画成一条更准确。

    四禅诸天：原书用楞严系，不是俱舍系 #

    原书第一章第 02 节所列色界十八天，四禅段作：福生天、福爱天、广果天、无想天＋五不还天（无烦天、无热天、善见天、善现天、色究竟天）。 这是《楞严经》卷九的系统，不含「无云天」。

    俱舍／瑜伽系则作：无云天、福生天、广果天（无想天摄于广果，故《俱舍论》卷八说「第四静虑处独有八」、色界共十七处）＋五净居天（无烦、无热、善现、善见、色究竟——善现、善见次序与《楞严经》相反）。

    A. 凡夫所居三天（有漏四禅，未断惑） #

    原书（楞严系）《楞严经》卷九所述俱舍／瑜伽系俱舍系所修功夫
    福生天苦乐二心俱时顿舍，粗重相灭，净福性生无云天下品（软品）第四静虑
    福爱天舍心圆融，胜解清净，福无遮中得妙随顺，穷未来际福生天中品第四静虑
    广果天于先心无量净光，福德圆明，修证而住广果天上品第四静虑

    两系并非逐名对应，表中并列只为方便查阅，不要把「福生天＝无云天」当成等号。「无云天」得名有三说并存：佛光大辞典「第四禅」条释为「云地轻薄，犹如星散」（本于《立世阿毗昙论》一类宇宙论）；普光《俱舍论记》释「在无云首故说无云」；另有异释谓此天无苦乐忧喜四受、仅有舍受，故称无云。三说均不宜径标为《俱舍论》原释——《俱舍论》卷八只列名未释。

    B. 外道所居一天（图上单列一格） #

    项目内容
    天名无想天。楞严系单列一天；俱舍系摄于广果天，不别立处所
    所修功夫无想定：以「出离想」作意修，伏灭前六识心心所令不现行（唯识系表述）。《俱舍论》卷五「前无想定唯异生得」，即外道所修，不属佛教四果
    寿命五百大劫（《俱舍论》卷五「修无想定…感五百大劫无想异熟」）
    劫数分布「初半劫灭，后半劫生」是《楞严经》卷九原文；俱舍系则说「生死位中多时有想，言无想者，由彼中间五百大劫想不起故」——初生有心、死时有心。两系描述角度不同
    果报《楞严经》只说「穷空不归，迷漏无闻，便入轮转」，未言必堕恶道

    C. 圣人所居五天（五净居天／五不还天） #

    天名俱舍系：杂修第四静虑品级现前心数楞严系次序
    无烦天下品三心第 1
    无热天中品六心第 2
    善见天上胜品十二心第 3
    善现天上品九心第 4
    色究竟天上极品十五心第 5

    《俱舍论》卷二十四：「由杂熏修第四静虑有五品故，净居唯五……谓下、中、上、上胜、上极品差别故。此中初品三心现前便得成满，谓初无漏、次起有漏、后起无漏。第二品六，第三品九，第四品十二，第五品十五。如是五品杂修静虑如其次第感五净居。」五净居次第，俱舍／瑜伽作无烦·无热·善现·善见·色究竟（上品＝善现、上胜品＝善见），《楞严经》卷九作善见→善现，二者相反。原书第 02 节列作「无烦天、无热天、善见天、善现天、色究竟天」，与楞严系一致。

    果位对应（通说）： 五净居天为三果阿那含所居，圣者于此继续断惑方证四果。

    色究竟天： 究尽诸色几微，为色界最胜。《楞严经》卷九「于舍心发明智慧，慧光圆通，便出尘界，成阿罗汉，入菩萨乘，名回心大阿罗汉」——利根者于此出尘界，不必另说「于此证阿罗汉」的单一判位。

    贴表时的四条注记 #

    1. 名单与总数：以原书的楞严系为主线。 俱舍／瑜伽系作「无云天、福生天、广果天＋无想天＋五净居」；楞严系作「福生天、福爱天、广果天、无想天＋五不还天」。色界总数三说并存：《俱舍论》卷八「此欲界上处有十七。谓三静虑处各有三，第四静虑处独有八」——无想摄广果，故八而非九；同卷又引异说「色界处但有十六。彼谓即于梵辅天处有高台阁名大梵天，一主所居非有别地」——大梵摄于梵辅（经部一类计）；通行的十八天说则别立无想天（《长阿含·世记经》《起世因本经》及辞典通行说）。另需注意：《瑜伽师地论》卷四的「十八处」＝四禅八＋大自在住处（无想仍摄广果），与通行「十八天」名同实异。

    2. 「无想定」不是图上的「灭受想定」。 无想定是外道以出离想作意所修的世间定，感无想天果报，定坏仍入轮转；灭受想定（＝灭尽定的异名）唯圣者能起。两者名相近而性质相反，主图上务必分置两处。但「灭受想定不感生任何天界」一句须修正——见上文「受想定」第 3 条。

    3. 净居天是「三果」的坐标，不是「阿罗汉」的坐标。 印光法师《增广印光法师文钞·与陈锡周居士书》原文：「若三界内见思二惑丝毫未尽，则生死根本未能斩断，纵令定慧力深，依旧无由解脱。如三果圣人，尚生五不还天，经许多劫，方证四果。若证四果，则生死根本断尽无余。」

    4. 往上接「菩萨乘」的那一格属另一系安立。 《瑜伽师地论》卷四：「复有超过净宫，大自在住处。有十地菩萨，由极熏修第十地故，得生其中」——于五净居之上另立，合成色界十八处；《俱舍论》不立此天（唯十七处）。

    但色究竟天与摩醯首罗天（大自在天）的关系属经论分歧，不可作定论：或说大自在天即居色界顶色究竟、为三千大千世界主；或说瑜伽系于净宫之上另立一处；大乘又说十地菩萨多作摩醯首罗天王、于彼成佛而人间所示为化身。这一格正好接主图「菩萨乘六度法」与「佛乘寂灭法」之间，但要注意它属瑜伽系菩萨道安立，与前面声闻断惑的刻度不是同一套，图上宜用虚线隔开并加注「另一系安立，三说并存」。
