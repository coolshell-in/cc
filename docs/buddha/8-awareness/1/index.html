    第一章 总说三经与修学次第 #

    《遗教三经》者，即《八大人觉经》《佛说遗教经》与《四十二章经》。今先学《八大人觉经》。此经篇幅虽短，仅列八条，然义理丰富，切于实用。经中道出佛法修学之次第，将道次第总纲阐示无遗：自入佛门，内心先建立根本知见；依此正见，再修持、行持；进而自利利他，终归发菩提心。次第分明，脉络清晰，故为初入佛门者修学之首选。

    初学佛者，若第一步含糊笼统，则此后修学之路必多艰阻。当今修学佛法者众，然能建立正确知见、依次第入手者甚少。多有学佛多年，犹不知从何下手，亦不察自身问题所在。其修学笼统，概念模糊，此处学一点，彼处学一点，于现实生活中能受用者寥寥。

    今观佛教徒之修学，大抵两类。其一，入佛门后一心扑于慈善、义工培福、遍赴法会，此类占大多数。其二，宿有善根，一闻大乘佛法即生感动欢喜，自感具大乘圆顿根机，此固为难得；然问及事修从何下手，则茫然不晓；问及如何将所学大乘智慧运用于现实生活、如何验证修学之进步、以何为修行感应之凭据，则道不明、说不清，不知具体操作。

    即如基本概念，试问：何谓「诸法空相」？空相如何具体观察？日常生活中面对缘起境界时如何操作？何谓「无我」？无我如何修、如何观？小乘无我与大乘无我差别何在？修无我之具体内涵为何？多不能言其所以然。无常故苦、苦即无我，名词虽能道出，然具体内涵讲之不明。既不知观察，便无从操作，终能解脱到彼岸者，鲜矣。

    是故修学佛法、发心修行，须觅得正确下手处，能实际操作，学以致用，学有所归。依此八条觉悟之修学，真实体会修学内涵，使之具足、落地，而有真实导归。其要在于面对烦恼、境界时，知所操作。今听经者多，然境界现前、烦恼起时，令其观察烦恼、观察无我之境界，则观不起来，病在概念模糊。而概念模糊之根由，实为缺少恒常思惟之熏修。早晚课诵、静坐之际，每日当以两三次思惟法义；思惟既久，方能生起力量。平日无思惟之觉慧，境界现前便无从操作。此乃当今修学佛法之一大弊端，不可不察。

    第二章 学习因缘：道心之发，实由欣厌 #

    佛门修学，最基本者在生死心具足。谛闲大师于《大乘止观述记》中云：「道心之发，实由欣厌。然众生久在迷途，若无佛法常为熏习，欣厌即无从生起。」此语道出策发道心之根本，即欣厌心，亦即生死心。欲发心修道，须具欣生心与厌离心；而欣厌之心，由知苦而来。人不解苦、不知苦，则欣厌无从生起，道心亦无从策发。

    然众生久在迷途。自净土门言之，轮回六道，不知归心西方净土；自圣道门言之，背觉合尘，迷失本性，不知回归自性净土。久在迷途，已养成习惯性之颠倒：静坐无事，即胡思乱想；闲来无事，便打妄想，今日想此，明日想彼，习惯攀缘。此颠倒不需人教，无始劫来，轮回之中即如是度日，非一朝所能转。具体言之，即四种根本颠倒：以不净为净、以无常为常、以苦为乐、以无我为我。

    此习惯性之无明颠倒，若无长时佛法熏习，无明之心无由转变。观乎平日：一日在家拜八十八佛，晨念佛号万句，复听经闻法，心即安定，纵遇家中烦扰，亦觉无碍；若三日不闻法、不拜佛、不念佛，则心散乱，一遇境界便起颠倒，攀缘难定，生死心更不易生起。听经闻法虽久，遇境界时仍起烦恼，欲修观而想不起来，即因无量劫来习气如是。可见生死出离之心，必于佛法学习中建立，是修出来的，非自然而有；修则有，不修则无。道心必由长时熏习而来：熏习既久，智慧渐开，乃能觉悟身心世界之虚妄，颠倒执取之心渐歇，生死道心方得生起。是故道心有其缘起，必经学习，不修则终不可得。

    第三章 知苦为出离之本 #

    今念佛者多，往生者少。何以故？佛号念得无力、不稳定，生死心不切、不坚固。生死心未建立于对缘起世间之清晰认知上，而此认知之根本，即是知苦。不知苦，何以知厌离？不知苦，何以体会世间苦、众生苦，何以发菩提心？无论小乘大乘，生死心与菩提心，必建立于对苦之深刻认知。

    然今人多不听经闻法，生死心多凭生命经验而来。感不苦时，佛号即无出离之力，念之有所保留。苦有三种：苦苦，众生皆知远离，畜生亦知厌离；坏苦，乐亦无常，乐亦是苦，鲜有人愿离；行苦，更不必言。故对苦之认知，须着力强化。纵现前生活圆满、健康自在，欲求出离，仍须日日听经闻法、修观。福报大者尤须留意：日日圆满顺利，执取心日积月累，生死心更难生起。若对苦体会不深、认知不彻，则易将修行空洞化，不复体会闻法之宝贵、修行之价值。

    然佛法言苦，非消极悲观地看待世间，而是教人如实观察现实真相。深入思惟观察，乃知现前所认之现实，非其本相；愈观愈明，愈信佛语真实不虚。故苦之认知，须彻底化、清晰化。

    知苦之「知」，非世间「知道」之知，而是依佛法思惟、体会、观察、观照所生信解之力，是一种智慧观照。由此知三界六道依正二报生灭变化，生命不可主宰、不可掌控，乃知厌离。欲求解脱，须知苦之根源，从苦因下手，不从苦果下手。苦因即集，谓见思惑与有漏业：贪嗔痴慢疑、身见，五钝使、五利使。断集则苦果自灭。若对苦谛不解，集谛亦不能解；不知苦因所在，即不知如何灭苦，修行便无从入手。八苦之名——生老病死、爱别离、怨憎会、求不得、五阴炽盛——虽人人能说，然具体内涵若不晓，观念笼统模糊，修行即无底。目标与敌人在何处尚不知，何以用功？对苦谛不解，道心生死心皆不能起，修行空洞化。纵表面精进，方向既错，精进反成另一种懈怠。

    由知苦而厌离，由厌离而求出。既求出离，当知去向：慕灭。佛陀以极乐世界依正庄严示于众生，令生仰慕：娑婆苦，极乐乐，立判高下。此是修行之果。欲得其果，须修其因：净土之正因缘起，即信、愿、行三资粮。缘起法通于十法界：信轮回，即应信极乐；有三恶道之因，即有极乐之果。印祖修行为何力道强？以「死」字挂心头，对世间无常之苦感受深，生死之心即迫切。

    第四章 释经题（上）：「八大人觉」 #

    「八」者，约数标名，谓八种觉悟之事。经题可从因果二地解读：从因地言，凡夫依此八法修学，转凡成圣，趋向菩提佛果；从果地言，菩萨大人因修此八法而成就。一为凡夫修学之因地，一为八法成就之果地。

    「大」者，非大小之大，乃大乘功德。诸佛菩萨内有戒定慧功德，破烦恼而成就自利；依大悲心施设善巧方便，令众生离苦得乐，成就利他。故大乘功德能自利、能利他，此就果地言。就因地言，大即大行大愿。凡夫发菩提心，亦是菩萨大人，然无内在真实功德，唯是假名菩萨。

    「人」者，菩萨大人，区别于未发大心之凡夫与二乘人。

    「觉」者，自觉、觉他、觉行圆满。以八种菩萨之法自觉，复以此觉悟他人，终至觉行圆满。觉行圆满，从事相言，自觉则一切世间法彻底觉悟，觉他则度尽一切众生；然众生无量无边，本为虚幻，众缘和合，本来无生，无所谓度尽不度尽。从理体言，如《圆觉经》所说「圆满菩提，归无所得」：透过八法修学，破尽我执、法执，方为觉行圆满。度众生只是手段，众生本如梦如幻；发菩提心、行六度万行，最终目的在破尽我执、法执。

    何谓「圆满菩提，归无所得」？觉悟之时，无能度之我，无所度之众生，无我相、无众生相，然仍以大悲心为体，炽然修六度万行度诸众生。菩萨依大悲度生，复依般若波罗蜜照了：能度之佛菩萨、所度之众生，皆如梦幻泡影，毕竟了不可得，唯是一念心所现之幻境。如梦中度生，梦醒之后，梦中之人与所度众生，除一念心外皆不可得。真正开悟证果之菩萨，觉行圆满，方知过去无量劫修六度万行，似有能度所度，实则除一念心外一切法皆不可得，一切法皆是实相之全体大用。我执、法执破尽，能度所度如梦如幻，唯此一念明了之心，是名成佛，是名「圆满菩提，归无所得」。

    第五章 释经题（下）：「经」义 #

    「经」者，梵语修多罗，此云契经，有二义：一曰结集，摄持义理；二曰勘订，裁断义理。

    结集者，如绳贯花鬘：佛陀所说无量义理，经以语言文字贯串之，成就经典，令众生摄持在心，依之而行。勘订者，如木匠绳墨：以经典裁断世出世间法之义理。世间一切发生之事，过去、现在、未来，佛经皆已说清；以经衡量世间法，无有出于佛语之外者。然经本为语言文字，属无情法，不能自摄持、自裁断，必由学人摄持在心，方能裁断义理。

    契经之「契」，又有契理、契机二义。佛弟子修学任何法门、听任何法师讲经，所闻之法须契合佛陀所说三法印之理——诸行无常、诸法无我、涅槃寂静；亦须契合自身修学之根机。今附佛外道甚多，所言与佛法相近，听者多觉相应，然其理不契三法印。彼或能医病、算命、卜卦，教人行善积德，却绝口不提「世间无常，国土危脆」，不提福报难抵生死业力，不劝人求出离，所说皆非佛法。自修亦然：经典虽契佛理，是否契自己根机，亦须自判。是谓契理、契机，故名为契经。

    第六章 闻思修：皈依四正行 #

    经之义理，如何摄持在心、裁断义理？《瑜伽师地论》示皈依四正行：一亲近善知识，二听经闻法，三如理作意，四法随法行。前二属闻，第三属思，第四属修。依此善巧方便，即能将佛陀所说文字之理摄持于心，再以此勘定世出世间法之邪正真伪。

    亲近善知识者，说法之人须有自证功德，具戒、定、慧三学；利他则须有慈悲心。具此功德，即应亲近。一切善法生起，皆由善知识开导，佛法重在传承；否则自看经典，易错认消息，误解佛意。亲近善知识，为抉择正法。

    听经闻法者，何以须闻法？欲了脱生死，先须知理。众生在生死大海头出头没、六道轮回，因颠倒故。众生本具佛性，皆可成佛，然因颠倒，隐没本具功德，不能显发。虽为生死凡夫，乃至三恶道众生，皆夹带佛性之力而轮回。欲了生死，先破颠倒无明之心；破颠倒，先听经闻法，了解正确之理。若无佛出世，众生无由得解。如《广论》所云：「佛非水洗众生罪，亦非手拔有情苦，非将己德移于彼，唯为说法令解脱。」佛陀不以甘露洒顶而消人罪障，不以威神拔人出苦，亦不能将己功德移赠众生。业在自心，还须自性醒转，自心解决。颠倒由心起，还须正知见破之。佛之大慈悲大神通，不能代众生受报。《法华经》衣里明珠之喻：众生本具无量功德珍宝，因颠倒而不自知，如衣中藏珠而行乞，仍过穷日子。开显此珠，还靠自己之力。佛陀出世最大利益，即开示悟入佛之知见。

    今人好花钱消灾、祈求平安，然不知灾从何来、福从何生、根本缘起何在，虽跪拜一生，灾不能消，福不能至。三界唯心，万法唯识，业在心里，故消灾亦在心里：听经闻法，开智慧，转念头，业即随转，此最直接、最根本。纵有重罪，转念之后所遇之难，亦是重罪轻报。心若染污，如镜蒙尘，虽佛光普照，亦不能感应道交；开智慧以拭尘，心镜明亮，念佛拜佛方时时感应。佛菩萨以大悲为体，时时加被，唯众生不肯伸手相应耳。

    如理作意者，作意是带动身口意三业之最重要心所；加「如理」即清净义。作意随正法思惟，三业清净；随贪嗔痴，三业染污。学人听经闻法后，须不断如理作意。未学佛前，一念起皆随自我意识保护自己，六根缘六尘，皆执为真实，于执实中起惑、造业、受苦，是为不如理作意。如理作意者，面对一切境界，将所闻法义摄持在心，清净作意：不增不减。增益之过，谓于虚妄不实之境界执为常、乐、我、净；损减之过，谓拨无因果，以为事出偶然、无有缘起。远离增益、损减二过，即名如理作意。法义摄持在心，不断运转思惟，面对境界即能保持智慧觉照。

    法随法行者，法指涅槃、无为，即灭谛。世出世间法中，以涅槃最为殊胜；修净土者，可以极乐世界为清净法。法随法行，谓一切身口意行为随顺于涅槃、随顺于往生极乐之目标。闻法思惟之后，须将苦集灭道之理付诸实践，时时调整身口意：所作能否增益信愿、随顺往生？不能者即不作。如欲购车，则日日行为须随顺赚钱之目标。以目标为引导，身口意随顺而行，是名法随法行。

    第七章 修学纲要：八条总览 #

    八条者，依次第可分为建立知见、自行化他、发菩提心三大段。

    一、建立知见，入道初门 #

    初入佛门第一件事，即打开指南针，厘清修行方向，不盲修瞎练，不随处乱跑。第一觉悟「世间无常，国土危脆，四大苦空，五阴无我」，即八正道之正见；有正见方能带动正语、正业、正思惟、正精进、正念、正定。此无常无我之见，非小乘独有，乃《八大人觉经》大人之法，是菩萨之无我。正见建立，宗旨确立，后之少欲、知足、精进、布施乃至发菩提心，方不致偏离。

    二、自行化他：先断恶，后修善 #

    断恶即少欲、知足（第二、第三觉），修善即精进、多闻、布施（第四、第五、第六觉），第七、八觉属利他。何以先断恶？如杯盛毒药，虽倒出而不洗，甘露入内即与毒相混。贪嗔痴烦恼即毒，修善法前须先调伏粗重烦恼；不尔，所修善法夹杂烦恼，反引至三恶道。多有修行人越修我相越大，好为人先、喜作主宰，做好事而依烦恼之力堕落，即因正见未立、粗惑未伏。故断恶为先。

    三、常修少欲 #

    思惑虽多，欲贪为首。《圆觉经》云「三界轮回淫为本，六道往返爱为基」。贪欲为第一大障碍，诸思惑皆由贪起。对治之法，依无常无我之正见，以无我智慧修少欲：减少内心欲望，降低攀缘心。少欲之目的在自在，「可悟无为而得自在矣」。

    四、常念知足 #

    既修少欲，复修知足。对外界要求不多，对已拥有者知满足，方能专心慧地，安心道业，守住一念心。粗惑调伏，再修六波罗蜜方不被染污，有正确会归。少欲知足之关键在自在：对外要求愈多，愈不自在，愈难得幸福，愈不能用功。

    五、常行精进 #

    少欲知足之后，须防安于现状、以知足为借口而懈怠。「倘讬言知足，而反坐在懈怠中，则堕落不浅矣。」佛法修行无原地踏步，不进则退。四正勤者，已生恶令断，未生恶令不生，已生善令增长，未生善令生。少欲知足是前方便，令心安定而能精进；非舍弃一切事而空坐，乃舍弃无意义、浪费时间之事，专心修习圣道，成办了脱生死、成就菩提之大事。

    六、深入经论 #

    精进而无智慧，即成暗证之愆。用功拜佛、念佛、打坐、诵经，而无正见智慧引导，不能了脱生死。精进波罗蜜依止智慧。不广学多闻，知见有局限，执一点为全面。修净者一句佛号统摄三藏，是开悟之人方有之境界，未悟不可妄自标榜。广学多闻，则法宝多、善巧多，易突破，能察觉起心动念之微细。临命终时，一念差错不能有，须了解自身习气烦恼，分得清随顺真心、妄心。解门广，能断疑生信，增长信愿，行门方有明确导归。专修与杂修，不以法门论定，而以心是否清净、方向是否明确、所学能否用上为准。慧天长老净土讲得好，然早年研读永明延寿《宗镜录》六遍，方会归一句佛号；诸祖师皆先有深厚铺垫。

    七、栽培福报 #

    有慧无福，难以利他，自利亦难安住。福报不足者，道场住不安稳，此处起烦恼、彼处亦起烦恼，坐不住。福非解脱正因，然为增上缘：临终无病痛，易提正念。布施、放生、供养，亦在对治悭贪，有破恶之用。福报大者言出人从；因缘具足，宜福慧双修。净土法门慧稍偏重，福可带修。三檀者，资生（财布施）、无畏（无畏施）、法（法施）。

    八、发心离俗，志求大乘 #

    发菩提心，住持正法。利他分方便行与正行：方便行即发心离俗、出家修梵行，正行即大心普济。虽修智慧福德，若不永离居家五欲，终日尘劳，无暇用功利生。出家相为解脱相、众生福田，住持佛法最为殊胜；然今圣僧难遇、众生福薄，在家居士护持弘法，亦不可缺，二者缺一不可。

    现出家相而不发心成佛、上求下化，即是小乘，悲心不能周遍。阿罗汉慈悲，然入偏空涅槃后不乐度生，不如菩萨「虚空有尽，我愿无穷」。然亦不可轻慢小乘：阿罗汉是圣人，凡夫犹未具自利真实功德，连提鞋之资格亦无，仍当随喜赞叹。

    八条虽有次第，目的唯在觉悟。学《八大人觉经》，要在身心世界如实观照。尤其第一觉悟「世间无常，国土危脆」为核心；此一觉不能建立，后七条难以实施，自利智慧亦无从建立。修学纲要，至此而竟。
