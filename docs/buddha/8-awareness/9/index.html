    无我可放·精进破怠·我见难调

    2026-10-26 Atom.X

    《佛说八大人觉经》讲记 · 第九讲

    承第一至第三觉，以「四大苦空，五蕴无我」之智慧观照事相；第四觉「常行精进觉」——「懈怠坠落；常行精进，破烦恼恶，摧伏四魔，出阴界狱」之流转门与还灭门、懈怠之相状与果报、《四十二章经》与《大智度论》之喻、染净善恶标准与三世怨；并附讲者关于我见难调、当家不易、感恩不轻慢之体悟

    一、承前：以无我智慧观照事相 #

    自第一觉至第三觉，所讲虽多涉事相，要皆扣住第一觉「四大苦空，五蕴无我」之智慧，以般若甚深见洞察烦恼与世间之虚假性。学佛既久，拜佛、持戒、布施亦颇用力，而心仍攀缘世间法，其故在未见真相：未以智慧觉悟生死过患与佛法长远之真实功德。无此观照，终必复归世间，与世人同其追求。

    佛法之真实功德无相，看不见、摸不着，难以事修速得；凡夫内有烦恼涌动，外有因缘诱惑，难期短时感受。世间五欲则立竿见影，故无智慧观照、内心未生决定者，世间有相之利往往重于佛法无相之德。

    若长期熏修，能知如何照看现前一念心，以智慧给内心一个决定——今生方向何在。如修净业者，往生之志须极明确；此非仰信，必经事相历练与长久熏习而成决断，则人事因缘境界皆不能动，此路方能相续。

    二、真实功德与世间过患 #

    真知净土功德与世间过患，经闻思修而生甚深决定者，必有生命之抉择：今生什么都可以舍，唯求生净土；此抉择常持不舍。

    昔有老居士言：世间事忙，待忙完再学，届时自然放下。此不可能，不合缘起。无平常之觉悟，则无临终之觉悟；今不能放，临终亦不能忽然而放。临终之放下非勉强造作，必是自自然然。

    平常不对治现行烦恼，境界来时不肯突破，唯求外在安慰护佑，而期待临终助念——纵有助念，纵广结三宝因缘，其时亦未必听得进去。寺院本清净庄严，而人多于其中照样起烦恼，不优于世间未学佛者。世间人起烦恼，喝茶吃饭即可了；寺中起烦恼，不能以五欲遮庇，当拜佛、念佛、忏悔、思惟法义以调伏。然多数人起烦恼即推责外境他人，鲜有反观求忏悔者。

    三、临终正念来自平常功夫 #

    在三宝中因缘具足、第六意识清晰，旁有法师同参开导授法，尚不能止此一念烦恼，乃至于三宝中造诸口业；则临终卧于病苦，纵有助念开导，岂能听得进？今有善缘而烦恼尚不能突破，临终凭什么能突破？

    临终真正往生，唯是一句佛号，无暇思惟法义，无暇准备，是真正万缘放下、通身靠倒。其时亦无「我要放下什么」之念，第六意识亦未必清明。往生只是一句佛号自然提起，故临终正念必是平常功夫之积累。

    四、烦恼即我：无我可放 #

    第一觉若真了解，则知并无另一个「我」决定要放下烦恼——烦恼即是我，妄想即是我。人之所来本是妄想：过去生颠倒无明，因缘和合，虚妄有生。若以为有一个「我」要把什么放下，即是仍抓住那个我不放。那个我之本质即是烦恼心所，自心捏造一个妄想的我，以为它有所烦恼、有所放不下，殊不知它本身即是烦恼。今所累积之烦恼即是我；心无厌足、惟得多求之贪欲烦恼相即是我。若存「临终自然放下」之想，临终必不能放，以不知放下何物故。

    真正往生者，一句佛号与弥陀感应道交，其间无「我要放下」之念；有此念者仍是妄想分别。所当放下者即此自我，自我即颠倒、即烦恼、即妄想，此正是痛苦、不自在与轮回之根源。

    凡夫计四大色身、计色受想行识为我，而受想即是烦恼；第一觉明言四大五蕴皆无我，故所当放下者岂非即此我？我即是烦恼，烦恼即是我。再起烦恼时当觉悟我不可得：无真实之我在起烦恼，此烦恼心所即是我，而我本不可得，故烦恼亦不可得。

    凡夫守护自我，外境一动即本能自护，此保护正是烦恼根本——本无我，所护者何？正是头上安头。故平常多思惟此八字，较易突破我见身见。

    临终对此八字若稍有体悟，即是动摇生死根，其时多少能体悟《金刚经》「一切有为法，如梦幻泡影」。真能照破身心之虚幻，则外境不能动，临终亦无「我要放下什么」之想；若仍在想，即难感应道交。其时无此念，方是真正之放下。故不可存「今不放下、临终自能放下」之侥幸：外者纵可放，那个颠倒妄想之我终不会放。

    五、万缘放下与通身靠倒 #

    净业之要与弥陀感应道交，在通身靠倒、万缘放下。「万缘」包括那个我，包括一切有为法，皆须放下；此与圣道门无我之思想相随顺。临终连「我要放下」之念亦不必有，唯「阿弥陀佛」一句，感应道交往生只在一刹那。

    故即一净土法门，念佛亦有诸多微细观念须处理，不觉悟则不知问题所在。关键知见须先建立，不然修之久而不得上路，不知何故久修无进步。

    六、第四觉·常行精进觉：经文与二门 #

    第四觉就懈怠与精进言之：「懈怠坠落；常行精进，破烦恼恶，摧伏四魔，出阴界狱。」

    第二、三觉言少欲知足，然此只是修学前方便，令心少攀缘、得寂静。既已少欲知足，次须精进。就消极义言，防人谓我已少欲无事，日日而过，自自在在；少欲而不思进取即易懈怠，一懈怠则滋长烦恼习气。佛法修学，不进则退，无原地不动之理，懈怠者必放纵烦恼，必致堕落。

    少欲但就世间染污有漏法言；于佛法之追求则非少欲，仍须有希望，须发菩提心、生善法欲。佛法令人放下，正为更好地提起。

    第四觉分二门：流转门「懈怠坠落」——因与果；还灭门「常行精进，破烦恼恶，摧伏四魔，出阴界狱」——依精进因缘得三种功德果：破烦恼恶、摧伏四魔、出阴界狱。

    七、懈怠之相 #

    《成唯识论》云：「云何懈怠，于善恶品，修断事中，懒惰为性，能障精进，增染为业。」谓于修善断恶之事，身懒心懒。

    解门之懈怠：于听经闻法无善法欲，法师要求方来，听个大概，含糊笼统，不以文字般若观照现前一念心；或谓听经太耗心力，一切从简，但念佛号——然念佛亦念不下去，于是四处走动、朝山旅游，手持计数器掐数，念佛而打妄想，无聊则打电话说长道短，心中本无生死、无菩提。

    行门之懈怠：当拜佛打坐、忏悔业障时，浑身不适，遂谓不如走走放松；护持大众出坡时，因私欲不愿，觉是浪费己时，众事能拖则拖。此诸懈怠，皆围绕我见身见。

    八、懈怠之果：坠落苦海 #

    不对治懈怠、不积功累德，则坠落苦海，分现世与来世之苦。修学佛法无绝对保持原状，古云学如逆水行舟。随众上殿过堂，而心所未动，不知所作何事，无积集往生、成佛资粮之动机；心既未动，一切所作皆成无记业，清净业种子不能成就，不构成解脱之因、菩提之因。在家人离寺更散，看似清静，然此懈怠已隐含坠落因缘。

    何以故？无量劫来每一生之造作，于阿赖耶识中结众多业种子，如定时炸弹，终将爆炸。心所不动、不如理作意，则凡夫之心必有所住。初住于饮食睡眠，渐为五欲所转；由多添几道菜、多睡片刻而心犹不满足——以心不在法、欲未调伏，故愈求愈多，烦恼渐生，遂追求十恶业：身三、口四、意三。恶业既久，烦恼不能自控，终至觉一切无所谓；习气定性，再欲调伏则难。

    三五日不听经、不拜佛，至第六日欲用功，则心力提不上。盖懈怠既久，心所与愚痴相应，如机器久不用则生锈。心不可能无所住：不与愚痴共住，即与正法共住。故习气定性，出家人则还俗，在家人则于五蕴中翻滚，随顺贪嗔痴造十恶业，久则成「佛油子」。

    能自始至终常保对菩提之欣求者，实不多见。讲者尝亲见：居士初请法宝皆甚欢喜，劝以「请归当阅，尤须笔记」，而后能如是者甚少，法宝多原封退回。

    九、《四十二章经》与毒食之喻 #

    《四十二章经》云：

    人有众过，而不自悔，顿息其心，罪来赴身，如水汇海，渐成深广。

    修行人欲解脱，若宿世罪业、今生烦恼习气不能顿悔其心，不追悔、不忏悔、不对治，则罪业势力渐大：恶业种子以烦恼习气为滋润，既不断串习，心又不加呵责，如众流归海，终成深广，不可复控。每日拜八十八佛，正为日日呵责；不制习气烦恼，即是增长罪业势力。

    故不可谓「但随大众作息，日日而过，自能进步」；心所不动，不尝法乐，则不能持久。尝见人入僧团，日日而过，无计划无希望，终不能安住，此山望彼山，从不内观自心。懈怠则心不能安住道业，此即现世之苦；未来则堕三恶道。

    《大智度论》喻懈怠，如人食美食而杂毒药：初食不觉其毒，其味甚美；食之既多，甘其甜头；及毒发，苦不可言。懈怠之乐亦尔：初时舒适，似甚快乐，然其乐短暂，以此因缘，未来生生世世流转三恶道。故懈怠为极重之过失。

    十、染净标准与三世怨 #

    再深论懈怠：从解脱道与菩萨道言，先须立善恶之定义。人天道较易判，即世间善恶；解脱道则以染净为判——凡令轮回者通通是恶，以皆染污法故。此层次甚高，须有智慧成分，以菩萨道悲智双修。

    善恶定义不清，则虽精进亦可能盲修瞎炼，或造成更多染污。故先须智慧抉择，方谈「诸恶莫作，众善奉行」——此又归第一觉。第一觉「无我」之智慧不立，则染净标准亦无。虽知不应懈怠，而无标准，则精进亦未离堕落之因：本质仍在做轮回之事，精进亦另是一种懈怠。智慧未及，功夫必停留表层；虽努力护持三宝，而无标准，即是印祖所叹之「三世怨」：今生造善而无解脱智慧之因，福报愈大，来世坠落愈深。

    十一、我见难调：讲者之体悟 #

    讲者近年于此深有所感。修善断恶，事相上易行；而于内心妄想分别断恶修善、于颠倒我见染净之辨能决断放下者甚少。无论解门行门学之善者，众生最难调伏者即是我见：依自心想法看待一事，自然赋予定论，此时再讲亦无用。故人欲觉悟，除非先放下我见。

    讲者于菩提寺管理四五年，渐不愿与居士过多往来。初时皆善缘，欲来护持、安住、学习，多不拒绝，皆尽最大努力与以最好之食宿环境，然终多成恶缘。故反思：不如初不结缘，宁可初时拒绝，亦不要后来烦恼之恶缘。本意令人食住学皆好，而忘了自己有烦恼、能力有限；又低估众生妄想。娑婆众生需求各异，皆执己排他。此等恰遇不知拒绝之人，反令人多生烦恼，善发心终成结恶缘。

    修行不易：人皆有求解脱之心，亦肯用功，然欲转无始劫来一念烦恼习气，实太难。非谓学法稍具智慧，妄想即可转；尚须待缘。禅宗古德一见参学者因缘不在此即拒之，令往他处，以其理虽通达而开悟因缘不在此故。何况今时，诸事待因缘和合，须自己经历方能有悟。

    十二、当家不易 #

    讲者自述与其剃度师长期对立。其时不觉有慢心、对立心、执着心，自谓所执为是。后接管寺院、管理大众，初无经验；渐觉当家最难：人事财务一大堆，最易得罪人，人人皆望其作好裁判、满足己意，而实不可能——此要如此、彼要如彼。其法唯在劝和，愿以最好与人、护持大众，常言「各人管好自己，莫管他人之事」。然无人能解，所见唯其种种过失——以当家故，当面与善，背后极言其非。

    受用现成之际，无人体会此须多少努力因缘，唯嫌此嫌彼；不能满足其妄想，则谓其无德、无能。无人体会无水无电、屋破饮食不佳皆来寻，政府、宗教、公安、消防、佛协、村委皆来寻；亦无人体会打佛七、讲经说法皆须通盘打理。居士于殿中拜佛无人相扰，挂单来寺但出坡学习亦无人打扰。然众生之心闲不下来，偏喜管他人事、搞是非。

    十三、不相应即离 #

    故当记：无论至何道场，若实不相应、不达所求，觉常住不清净不如法，则合掌令欢喜，离去即可。可不护持，可护持自认为清净如法之道场，皆随喜赞叹——三宝本是一家，但能成长、道业成就，往何处皆随喜。然不可坐于道场中拨弄是非，言此道场如何，复告于外人；虽世间人亦不至此，此为最起码之规矩。

    精进者不可以己之要求要求他人，各人因缘不同。人人管好自己，则道场清净。又有初入佛门者，颇具道心而过于理想，谓当闭门用功，自然龙天护法；然早餐无菜则望加菜，夜中饥饿则望开火。当家者须虑：晨加一菜，则大寮执事更忙更苦，苦则起烦恼，烦恼则离去。提要求者不虑此，唯虑是否满足己意；不能满足，则虽百般解释亦无用。故当家最易得罪人；不在其位者，永远只是主观。

    十四、感恩与不轻慢 #

    出家法师之最难有二：一者非法身菩萨，不能尽满人愿；二者未成居士心中之样子，则彼即起烦恼。各人生命经验、受教育程度不同，不可以己之想法要求人人同己。

    讲者昔与剃度师辩论，气极而挂电话，师以为不尊重、不知感恩。其时自谓道理懂得较多，以「最好之感恩即学法弘法」为辞，以坚固我执与师辩解。今思之，此非法执，乃坚固我执；所学之法被我见我执染污。今既醒悟：但凭剃度师成就出家因缘一条，无论师如何，皆当深深感恩。

    其剃度师尝当面训之，谓：不通感恩，则连最基本之世间法与做人之道亦有所缺；法虽学得再好，终不能受用。讲者今完全承认此语，然当时处境界中，无经历故无法体会，亦不承认己过。

    故当记：无论能力多大、何等用功，皆不可轻视任何人、任何道友；不可总觉得他人无修，不可妄想他人成为自己心中之样子。又当常存感恩心、柔软心。纵此人不能满足己意，但于己有一丝之恩，皆当感恩；纵无恩，亦不可以对立心、嗔烦恼对待——己是欲成佛之人，未来因缘终当度之，特今缘未具耳。菩萨度生，皆慈眼视众生。佛世出家人住阿兰若、出家在家必分者，正以出家人亦有烦恼习气，而众生妄想分别甚多；居士见寺院事，既不解又过于理想，不合则起烦恼，起烦恼复肯定烦恼。故保持距离最佳。

    十五、烦恼起时之对治 #

    修内心染净之事，有烦恼必勉强自己跨越。烦恼妄想实不能控时，不与任何人言语，不向任何人倾吐，独处静一静、走一走、拜拜佛。否则烦恼既活动而不能自控，向此人倾吐、向彼人倾吐，终将带动一切恶因缘；身口一动，又是一重新业。今网络发达，造业尤易。故于内心妄想烦恼，须以智慧决断，不令有滋生之空间；外境如何不佳，暂且不管，先看好现前一念心。实不能跨越，亦不起烦恼，合掌令欢喜，保持将来得度之因缘，当下护持清净心与菩提心。

    十六、结劝：以佛理照自身 #

    讲者自述经历，非针对任何人，乃以个人体悟相告。诸多道理纵已懂得，而未经历、未体悟时，不能真认可佛陀所说之理。众生最大之病，在好以佛理照见其他一切，而鲜有能照见自己妄想烦恼、将自家妄想烦恼完全否定者——此最难。以道理讲人极易；面对自己内心，烦恼妄起时当下照破，不令生虚妄分别，此最难。

    故须不断思惟：此理非学即能明，必日日思惟、闻思修，方能渐得松脱。烦恼习气，理虽已懂，若无五六年、七八年之训练，无缘之和合，实难跨越。

    结语：合掌回向，愿共成道业。
