    广学多闻·闻慧具足·念佛八误区

    一、唯慧是业，临终正念 #

    第三觉言「安贫守道」，其要在有限光阴中抉择世间与出世功德，不因世事而失佛法广大功德之求；故当多花时间听经闻法，「唯慧是业」。如是方能于每一事、每一问题得一深刻之道理。此道理非徒听来，乃平素观察生死轮回真相，自内心自然流露，又经唯慧是业之思惟学习、历境淬炼而成。唯此认知能看清世间真相，临终心不贪恋、意不颠倒，此即临终正念。此认知一旦成立，方能体会人生难得、佛法难闻、净土难遇，不辜负得人身之胜缘；若此不立，则日日晚课诵「是日已过，命亦随减」，亦无所用。

    二、还灭门总纲 #

    今续学第五觉之还灭门：「菩萨常念，广学多闻，增长智慧，成就辩才，教化一切，悉以大乐。」前二句就自利言，后二句就利他言。

    三、自利首在广学多闻 #

    愚痴为生死根本，欲破此愚痴，须藉圣言量之语言文字，知何为生死根本、何为出生死根本；何种心、何种造作随顺生死，何种心、何种造作随顺清净涅槃。由闻方能渐寻问题根本，知所下手，渐得出离。故菩萨当常忆念、广学多闻。

    其利有二：一者看清了生脱死之路，不盲修瞎练，不致一味前冲而不知所至；二者拓展对法之认知。众生心极复杂，烦恼种种，须不同法门对治不同烦恼。

    四、一句法语，四种判教 #

    如天台藏通别圆，一句法语可有四种解释。若不广学多闻，闻甲法师以藏教释之、乙法师以圆教释之，便不知所从；实则皆无错，只所站角度不同、所判层次不同。

    又如「诸法因缘生，诸法因缘灭」，上根者闻之即契无生，以诸法不可得、因缘生法亦不可得故。然此智慧非今生可成，乃过去无量劫栽培波罗蜜种子，此语只作触发之增上缘，令宿习之力显发，故当下成圣道。

    五、信愿由闻法建立 #

    常人若不思惟学习，不但不能契入无生，即对治烦恼，此语亦未必够用。念佛亦然：有人信根猛利，初闻即生绝对信心，此善根非今生始栽；有人闻而半信半疑，则须不断从理上、从各角度建立信愿。即此一句佛号，人人建立信愿之过程亦不同。

    故广学多闻，方能渐断疑生信、渐具信愿。会听经闻法者，学他经于念佛法门非走弯路，只圆满其菩提心、建立大乘圆满知见、增长信愿，成就正确之念佛缘起。缘起既立，则知念佛何以必往生、弥陀何以临终必来接引、何以十念必生、何以带业往生；临终不必外求，但安住此句佛号即可。净土虽特殊，亦有对应之缘起，即信愿持名，此缘起于诸经皆可觅得答案。

    六、增长智慧：闻思修 #

    「增长智慧」。徒多闻而无智慧，则文字相未经咀嚼，不得其中法义，不能真实受用；仅有闻慧，对治烦恼之力不足，须进至思慧、修慧。

    阿迦曼尊者喻：汤勺于汤中搅之久，终不知汤味；欲知汤味，须以舌尝。汤勺喻心：心于佛法语言文字上广学多闻、不断分别，若不实践，如勺在汤中搅而不尝，永不知味。故多闻之后，须长时间闻思咀嚼，方能体会法义、生真实智慧。

    初学菩萨欲进步、欲了解自己、欲建立正信正见，除多闻外，还须静坐思惟，并于现实中观照操作。切忌初即存门户之见、恃己排他；当开心量：越广学多闻，越了解自己，疑惑渐除，信愿渐足，临终方有正念之望。

    七、成就辩才，教化一切 #

    「成就辩才，教化一切，悉以大乐」，此从利他言之，是慈悲之流露。辩才非世间辩才：世间辩才动听而逻辑强，不能予众生究竟解脱。此辩才指出世利益众生之善巧方便；成就辩才，方能以种种方便利益不同根机之众生，予其究竟解脱乐、涅槃乐。

    当知今是凡夫位菩萨，见思烦恼俱在，理上或明，事上多不能行。然不能行，亦不因此舍所发菩提本愿；此愿当常推动前行。未有真实辩才时，行菩萨道但择一条即可：发愿必究竟圆满，为成佛道、为度众生；而维持此愿之落实，一两条足矣。以未分证法身，力不能遍办故。所择一两条无论偏于何门，临终弥陀即以此本愿之力与之感应道交。

    八、一行即摄万愿 #

    如十大愿王愿愿导归极乐，行之不必条条俱办。但修随喜赞叹，见众生行善、护持三宝，念念保持随喜，余者暂置，以力所未逮故。

    何以故？诸愿体同，所缘皆十法界有情无情，皆恒顺本性，故愿愿互摄。布施至极者必不伤害众生，故自断恶持戒；必利益众生而不与计较，故能忍辱；念念为众生，故与精进相应；心清净不为烦恼所转、不为境界所动，故与禅定相应；唯随顺无我者能真布施，故与般若相应。故落实一条，即能维持本愿。

    九、虚愿无力，真实愿坚 #

    放生布施皆可，要在愿缘一切有情、为菩提道求生净土。临终提起佛号，此佛号即具此愿力，弥陀即依此愿力与之感应。今以烦恼能力所限，须求生净土以速圆满；娑婆所发之愿虽多未行，实未曾舍，反以此愿速得往生。纵未成就辩才，至极乐留学已，再回入娑婆教化一切、悉以大乐。

    所最忌者，愿力不强、愿太虚浮，只有口头而无实质。发愿非随口之说，亦非佛前跪诵而已；要在佛前所发之愿，日用中能否保持不失、能否以此愿规范身口意。虚愿无力，临终虽念佛亦难感应，难破烦恼障，业力必大于愿力。佛前所发虽认真，未必坚固；真坚固之愿，必于历缘对境中淬炼而成。一切身口意之运作，当以愿力推动，又藉之加强愿力。

    十、心量渐增，愿力渐真 #

    今所发之愿，即他日「教化一切，悉以大乐」之资粮。念佛不可只为脱娑婆苦而求生——「此太苦，我欲往乐处」，此不合往生条件，力道不足。往生条件必具大乘利生思想，为菩提道求生净土。今人临终多不安详，正以力道不足；佛号虽多，不能与弥陀本愿相应。相应最速者：一者放下，二者心与弥陀心相应。

    故往生之愿须具体不含糊。既为利众生而往生，则念佛时须将众生之相置于心中；行一二条即可，而利益众生之心须恒常存在，此即菩提心。然所谓利益，非令众生于三界享福，乃令其出轮回苦、成就佛道。

    十一、蕅益补文：三失一得 #

    心愈正、愈殷重，则心量愈大，昔所挂碍者自然不挂碍，此即学佛之心日殷、渐有菩萨相之验。殷重心令所发之愿真实不虚，纵能力未逮，此心亦渐能起用。《楞严经》阿难言：「五浊恶世誓先入，终不于此取泥洹，将此身心奉尘刹，是则名为报佛恩。」以彼已得真实功德，故能承担。愿真而切，念念以利众生之心推动修学，久久自感法之真实功德。切忌法法相斗——禅与净争、净与台争，此即毁坏佛法。佛号有力与否，端在愿能否于境界中规范身口意。

    蕅益大师《八大人觉经略解》云：「虽云精进，若不广学多闻，增长智能，则成暗证之愆。又有闻无慧，如把火自烧；有慧无闻，如执刀自割。闻慧具足，方可自利利他。」

    十二、暗证之愆 #

    不广学多闻、不增长智慧，则闭门修行而无观照，依自妄想，无标月之指，即成暗证之愆。蕅益大师《金刚经破空论》言：明末禅者不看经典，偏空暗证，拼命修定；稍有相应便谓得无生法忍，实则或未到地定，初禅尚无。「暗」即无明，糊糊涂涂不知理，自以为得圣道。

    十三、以教印心 #

    若常听经闻法，有辨别力，则知以教印心，自知修至何位，无须他人印证。古人师徒有传承，师父明眼，弟子亦有宿缘，故可以心印心。今明心者希；若有人自言能为人印证开悟、明心见性，令众举手者，当速远离，非善知识。《金刚经》中须菩提言：若自谓得四果，即非；证四果者不自谓证，以无四果可得、已无我执故。今世岂有自言明心见性、能验他人者？故唯以教印心。

    念佛亦然：非谓有念即得佛力加持。心态不调，则难与佛感应；不调心而念佛，佛号只加强其心力——心力是嗔则加强嗔，执境界相则加强执。专心而无信愿，所成只是止；心有力量，反加强嗔与执。故精进须有智慧配合。

    十四、有闻无慧，把火自烧 #

    「又有闻无慧，如把火自烧。」闻而不如理思惟，多闻与智慧不能互增；仅有闻而无慧，如持火自烧。火喻贪嗔痴一切烦恼。闻法而不以之调伏现行烦恼，甚至增长：文字分别愈强，贪嗔痴愈炽，以佛法文字加持烦恼。学多而见己胜人则骄慢，见己不如则嗔嫉；文字反成系缚，此即把火自烧。火本欲烧烦恼之薪，今反烧法身慧命。提婆达多日诵万偈而终堕地狱，正以闻法为求名闻利养。

    临济禅师有问：禅宗明心见性与教下研实相，皆言众生皆有佛性，二者何别？答曰：「荒草不曾除。」谓教下虽学多教理，遇境不以之观心、不以之调伏烦恼，仍是文字上虚妄分别；法虽听入，不思其义，仍是虚妄分别。学教而不以教照心，即是有闻无慧，贪嗔痴之草未曾除，故不惟无益，终反害己。

    十五、有慧无闻，执刀自割 #

    「有慧无闻，如执刀自割。」此人慧猛利如刀，而不事闻法；朴实用功，念佛拜佛，日于行门着力，却不喜听经学教。刀喻邪见。用功打坐，心渐寂静；寂静中所生之认知往往坚固，然未经佛法智慧语言引导，即成邪见。善星比丘得四禅而谓得四果，中阴见未来六道境界，遂谤佛法谓涅槃非实，以谤法堕无间地狱。行门用功而无闻，不知修行路径，即如执刀自割。

    此类人有二特点：心寂静，故知见坚固；多福报，故言有摄受力。以邪见而具摄受力，遂以盲导盲，众皆随之同堕。其误人之法身慧命，故一堕比破戒者更可畏：破戒者若有知见引导，尚有惭愧，速出三恶道；邪见者心寂静有力，无惭愧心，坚固执持邪见，以错误知见作功德想，故难出离。

    十六、闻慧具足，自利利他 #

    「闻慧具足」，广学多闻而闻思修俱足，方可自利利他：自既有成就有功德，亦能利益众生令得解脱。多闻与智慧相互资助，缺一不可。

    同是多闻，有能生慧、有不能生慧，差别只在是否以佛法照心、对治烦恼习气：能以法照心，则闻生真实智慧；不能照心，则不知一念心之善恶染净，只是闻慧，不成思慧，更无修慧。《四十二章经》云：「博闻爱道，道必难会；守志奉道，其道甚大。」博闻爱道者，于听经闻法只是兴趣，故道必难会。须守志——志即菩提心，闻法为生死、为对治习气、为利益众生；又须奉道——依所学于寂静中修止修观，调伏烦恼。如是方生真实智慧。

    十七、念佛八误区总标 #

    学经终究会归净土，以增长信愿。今依古德文句，录念佛八大误区。末法之时，念佛法门为众生唯一救命稻草；而学佛环境日劣，邪见纷出，外缘纷扰，故念佛者众，陷误区者亦众，自误误人，得真实利益、成就往生者屈指可数。六字洪名看似简单，实则精深；若真解其奥，一念可超九品；若无正确之念佛缘起观，则不得其真谛。

    十八、误区一：执形式而忽心念 #

    其一，「执着形式，忽略心念」，对治曰「数质并重，返照自心」。或过重外相，在乎每日数量而心不在焉，念佛虽多，计数器掐之不已，而忽略专注与虔诚；无专注虔诚之佛号甚虚，如空胶囊无药。初学固不可少形式定课，然形式只是手段，为对治懈怠、养成习惯；每日一万两万，终须成就者何？内心之专注与虔诚而已。

    若一边与人语一边掐计数器，临终虽提佛号亦无内在，则不能相应。故念佛不在数量多广，而在一心不乱；每一句专注而相续，久久乃能心佛合一；心佛合一之一句，胜千万句散乱。只求数量而不求质量，如以沙煮饭。

    数量是外现，质量是内证。古德有反闻念佛法：不惟出声，更以自心听自心所出之佛号。如猫守鼠洞，目注洞口，鼠出即扑；念佛时心中有觉，观此佛号中有无妄想，妄想才出即便觉知，觉知即灭，如是方能摄心。

    十九、误区二：求福不求往生 #

    其二，「求福不求往生」，对治曰「深信切愿，专求往生」。此于老居士尤多。今人情执重，念佛但求家人平安、身体健康、事业学业顺利，回向皆此，于自身往生功德可有可无。讲者昔年于年节遇老居士，戏言「早些往生」，居士答「大过年的不要乱说」；问其平日念佛何为，则曰「保家人平安健康」。是把念佛作谋取现世利益之手段，非解脱法门。

    净土根本在信愿持名、求生西方。若只求现世福报，则违净土宗旨，难获真实受用。深信切愿有三：一者读净土经论，《净土十疑论》《无量寿经》《阿弥陀经》等，知极乐依正庄严；静坐时数数观想七宝池、八功德水、黄金为地、宝树、天乐，令其相状渐真。二者修无常观，思惟轮回过患、暇满难得。三者发往生之愿：晨昏各念「愿生西方净土中」「花开见佛悟无生，回入娑婆度有情」，至诚恳切。

    又有临终观想法：睡前观弥陀、观音、势至自虚空来迎，保此想象入睡。当知往生非舍离亲人，乃更好利之：至极乐成就，可乘愿力度化。故往生是利益眷属之最，现世所求徒增其轮回。

    二十、误区三：执理废事 #

    其三，「执理废事，空谈净土」。此多有佛学基础者。中国人好思惟、好智慧，故大乘佛法于此土有缘；而好学之人易溺于教理研究讨论，于五经、四料简乃至大乘经教皆有涉猎，独少念佛。净土解行并重，既须解理，亦须实行。末法根劣，执教轻修，如手持地图知所往而不行，终不能至。教理为坚信心、明方向，终须落于念佛；不落实则如画饼充饥。故持名为正行，教理为助行，本末倒置则难成就。

    对治曰「解行并重，实修为本」。古德有三法：一者三三制，一份研读、一份思惟、一份实修。二者解后即行，每研教毕即抽时操作：学一心不乱之理，便放书试念半小时；学《楞严》妄想本空，便静坐观「妄元空」，见效最速。三者月解日行，每月定数日专研教理，余日专修。末法之世，偏重仍在实修。

    二十一、误区四：断灭见解 #

    其四，「断灭见解，误解净土」。多人谓人死如灯灭，往生乃佛安慰世人之方便说，念佛真义只在安立内心；多修禅者亦然，以西方为象征比喻。持此见者，终不能与佛感应道交，如种播石上，岂能生根。

    净土法门建于佛之智慧慈悲，极乐实有。《弥陀经》中佛言，「我见是利，故说此言」：极乐依正庄严，佛亲眼见之，故如是说。故须深信极乐实有、众生念佛可生、弥陀救拔之力。「信为道元功德母，长养一切诸善根。」

    正信有三：一者佛说，大藏中述净土者二百余部。二者理证，心能造万法、极乐是唯心净土；净土不离中道缘起、不离一念心。三者事证，《往生传》《净土圣贤录》所载甚多。

    三疑三信者：疑己能否往生、疑弥陀能否接引、疑极乐是否实有。疑己者从业观：业亦虚妄，故可带业往生。疑接引者，弥陀不离一念心，故云「我在阿弥陀佛心中，念我心中的阿弥陀佛」。疑极乐者，极乐不离一念心之缘起。三信者：信自己决定往生、信弥陀绝对接引、信极乐绝对存在。三疑三信既决，往生之种已于心生根。

    二十二、误区五：烦恼未断不敢念佛 #

    其五，「烦恼未断，不敢念佛」。或烦恼重，来时便忘念佛，自谓根机陋劣，欲待烦恼断几分再念。当知净土正为烦恼众生而设；若待烦恼断尽方念，则十方无一人能念。正以末法业障深重、求出无门，故更须佛力加持。烦恼起时正是念佛时，不必待其熄灭。小烦恼直以佛号突破，不必先修观；若烦恼一来便修观，即是对弥陀悲愿之救拔有疑。唯重罪躁动难突破时，方以观对治。

    待烦恼灭而后念，何异病愈而后服药？待心情环境好再念，亦误解带业往生。净土之殊胜，正仗佛慈力、带业往生。

    对治曰「烦恼即菩提，带业往生」。如病人与良医，病愈重则求医愈急；烦恼愈重，愈须他力。故烦恼起时不压不放，自然转念念佛，以佛号之力代烦恼之力，令烦恼成念佛之助缘；当下一念向佛，烦恼即是菩提之因。起烦恼时可默念：今正生气，正是念佛之时；今既有病，当速服阿弥陀佛之药。

    又有忏悔念佛法：每日定时先忏悔所造恶业，再专心念佛，业障消除，兼增往生资粮。

    二十三、误区六：临渴掘井 #

    其六，「临渴掘井，待老念佛」。在家居士多作是语：「事业方展，又须带孙、烧饭、照顾家人，抽不出时间；待退休必当精进。」则应之曰：「可，但须肯来。」然是彼先来，抑无常先来？皆不可知。无常若至，忽然中风，卧床不起；人命无常，转眼即逝，生死大事岂容拖延。

    老居士年七十，犹言「待我老时再念」，七十而未老。此见全忽人生无常与临终之要。古德所重者：一者念无常，今日不知明日事，况遥远之晚年；二者今即养成长时念佛之习，关键时方能起作用。平日不念，老来方念，欲得一心不乱，几不可能。

    对治曰「及时修行，培养习惯」。一者碎片时间念佛法：等车、排队皆可默念，其要尤在养成随时念佛之习。二者晨午晚三定：晨起、午休、睡前各定十数分钟专念，务在规律；如是数年，乃至年老体弱，习惯犹存。三者专日念佛：每周抽一日集中念佛，不碍工作，又保质量。如储钱罐，日积一块，临终此存款即最宝贵之财。

    二十四、误区七：孤立念佛 #

    其七，「孤立念佛，脱离现实」。此多感性之人：初闻净土殊胜，又觉生死无常，遂欲速离世俗，乃至弃职、排斥家庭与社会责任；家人不解，强行修行，不惟不得法益，反增我执，致家庭不和。辞工作、闭门念佛，以世俗为牵绊者，此是逃离责任。因缘未了而逃避，非放下也；放下者烦恼，放弃者责任。

    故在家念佛，印光大师教以「敦伦尽分」，本分义务仍须尽；亦不离世间觉，于尽责中提升觉悟。此病出家亦有：讲者昔年当家，见道心猛发者一心扑于修行，不为公为众，众出坡共修则谓费时，闭户自修，此皆我执，与菩提心不相应。

    对治有五缘修行法：以工作为修福之机会，以家庭为忍辱之道场，以社交为修慈悲之平台，以挫折为修慧之师，以闲暇为修定之机。二者家庭共修法，然须福报。三者随缘不变：随顺世间因缘之变，而念佛初心不改。

    二十五、误区八：杂乱无章 #

    其八，「杂乱无章，法门不专」。或于禅、密、教理间比较优劣，虽亦念佛而行门不专，贪多求全，心力分散，终至样样通而样样不精。如掘井，凿二三米未见水即易地，掘之不已，终无一处出水。故念佛贵专念专修。

    对治曰「一门深入，长时熏修」。此世众生行门当专于持名，余为助；非排斥他门，乃集中精力。古德有「三不」：不贪多，观音、地藏、文殊咒等不必兼揽；不求快，不求短期即得神奇体验；不比较，不与人较境界进度。守此三者，方能于一门走远。

    又有二十一日专修法，七日、十四日亦可；每年择一清闲之时，闭门或入清净道场，连续念佛，不杂他门。又有主修辅助法：于他门有兴趣者，仍以念佛为主，修禅增定、研教增慧。

    二十六、偈颂八句与结劝 #

    修行贵在对症下药，识得误区，找准对治，事半功倍。此八者可自勘：己有何盲点、何问题未决，即速除之。古德有偈：

    「数质并重返照心」——数量与质量并重，常观念佛之一念心，是否守住此句佛号。 「深信切愿专西行」——所学何门，一切导归净土，晨昏发愿。 「解行并重实为本」——解门坚信心、指目标，然须行持，实修是本。 「正信培养如理明」——须有正知正见，须有正确缘起之念佛。 「烦恼即是菩提种」——烦恼菩提同是一念心，一念颠倒即烦恼，一念为众生求生净土即菩提种。 「及时修行成习惯」——勿待年老，平常养成念佛闻法之习。 「不离世间觉道生」——不执家庭亦不离家庭，敦伦尽分。 「一门深入证圆成」——行门须一门深入，方有力量。

    虽学《八大人觉经》，终在增长信愿、导归净土。

    结语。今课至此，大众合掌回向。
